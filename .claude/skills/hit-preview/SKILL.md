## 🛠️ **即下载即用方式（无需安装）**

本工具已将全部依赖打包到单个文件中，**下载后直接运行**，无需 `npm install`。

### **方式1：使用运行脚本（推荐）**
```bash
# 测试连接
./run-hit-preview.sh test

# 分析剧本（支持多集竖屏短剧，单次最多2200字）
./run-hit-preview.sh analyze -f 剧本.txt -p 抖音

# 生成弹幕
./run-hit-preview.sh danmaku -f 剧本.txt -p B站

# 带对标分析
./run-hit-preview.sh analyze -f 剧本.txt -p 快手 -r "十八岁太奶奶驾到"
```

### **方式2：直接运行**
```bash
node bundle-2.1.5.js test
node bundle-2.1.5.js analyze -f 剧本.txt -p 抖音
node bundle-2.1.5.js danmaku -f 剧本.txt -p B站
```

### **方式3：零配置安装（首次使用）**
```bash

```
此脚本仅检查 Node.js 版本并设置权限，不安装任何依赖。
