# 短剧剧本架构师

根据你输入的一段文字（主题、创意、灵感），自动生成短剧故事大纲和角色设计方案，并可生成真人风格的角色定妆照。

## 适用场景

- 短剧 IP 孵化：快速将灵感转化为可拍摄的故事框架
- 内容策划：批量产出故事概念，筛选潜力项目
- 角色设计：系统化构建角色档案，并生成真人风格的视觉参考图

## 使用方法

直接用自然语言描述你的想法，例如：

> "帮我生成一个都市复仇题材的短剧故事，主角是个被闺蜜和未婚夫联手背叛的女律师，她要暗中布局反击。"

也可以只说一个关键词：

> "职场欺凌题材"

信息不足时，技能会主动追问关键信息（主题方向、核心冲突、篇幅偏好），再开始创作。

## 输出内容

| 板块 | 说明 |
|------|------|
| 标题（5 个备选） | 飞卢风命名，突出核心卖点 |
| 基本信息 | 时长、集数、类型、一句话简介 |
| 剧情梗概（1500-2000 字） | 完整故事走向，含情绪爆发点和悬念铺设 |
| 人物设计（5 类角色） | 含外貌特征、性格、背景经历 |
| 角色定妆照 | AI 生成的真人影视风格角色定妆照 |
| 剧情结构（7 个节点） | 从钩子到结局的完整节奏框架 |
| 前 10 集分集大纲 | 每集情节概括 + 悬念设计 |

## 注意事项

- 生成的定妆照为 AI 真人影视风格角色参考图，面向真人演员的选角和造型参考
- 如需更精准的角色一致性，建议后续借助专业生图工具（如 Midjourney / SD）进行精修
- 所有文本输出为概括性陈述语言，不包含对白和场景细节，后续可基于此拓展为完整剧本
