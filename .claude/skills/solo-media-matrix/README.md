# Solo Media Matrix V2.0

一人公司自媒体增长与变现作战台。

它不是泛泛讲自媒体运营，而是把一个人的有限时间转成一周可执行计划：平台取舍、选题评分、一鱼多吃、7天排期、数据复盘、变现动作。

## 适用场景

- 一人公司想用内容获客，但不知道做哪些平台。
- 有一篇长文、视频脚本或直播内容，想拆成多平台版本。
- 每周只有 5-15 小时，需要现实可执行的内容排期。
- 各平台数据分散，需要判断下周加码哪个平台。
- 已有粉丝，想测试知识付费、私域、商单或带货。

## V2.0 重点升级

- P0: 统一版本为 `2.0.0`，修复 Windows 控制台中文/emoji 编码问题。
- P0: 修正选题评分公式，低难度高潜力选题会得到更高分。
- P0: 文档与代码能力对齐，避免承诺未实现的类和函数。
- P1: 新增 `OPCWeeklyOperator.generate_weekly_plan()`，一键生成完整周作战计划。
- P2: 标准输出加入 `今日动作` 和 `不做清单`。
- P2: 加入一人公司五套件协同逻辑。
- P3: 增加轻量平台风险检测、CSV 数据复盘、端到端 demo。

## 快速开始

```bash
python scripts/main.py
```

输出 JSON：

```bash
python scripts/main.py --json
```

带示例数据复盘：

```bash
python scripts/main.py --with-metrics
```

## 示例输入

```text
我是一个 Python 自动化办公博主，每周能投入 10 小时。
现在主内容是一篇《Python 自动化办公完全指南》长文。
目前有 B站 3000 粉、知乎 1200 粉、小红书 500 粉。
目标是 30 天内涨粉并测试知识付费。
请帮我生成本周自媒体作战计划。
```

## 核心输出

- 主平台、辅助平台、暂停平台
- 一篇核心内容的多平台拆解
- 7天排期和每项预计耗时
- 选题评分与优先级
- CSV 数据复盘和平台加码建议
- 免费引流、低价产品、中价课程、高价咨询路径
- 今日动作和不做清单
