# 一人公司五套件协同

Use this reference when explaining how Solo Media Matrix connects with the user's other OPC skills.

## Roles

| Skill | Role | When to Suggest |
|---|---|---|
| 创业思维导师 | Strategy, positioning, customer selection, offer design | The user is unclear about niche, customer, product direction, or strategic tradeoffs |
| 自媒体矩阵管理器 | Acquisition, content reuse, platform growth, creator monetization | The user needs content planning, distribution, analytics, or creator monetization |
| 电商运营助手 | Product selection, pricing, listing, live/short-video selling, customer service | The content plan involves selling physical goods, affiliate goods, or live commerce |
| 财务管家 | Bookkeeping, taxes, profit, cash flow | The user has revenue, expenses, invoices, tax, or profit questions |
| 法务助手 | Contracts, copyright, MCN, advertising compliance | The user signs brand deals, collaboration contracts, MCN agreements, or uses third-party materials |

## Coordination Principle

Solo Media Matrix is the acquisition front office. It should not try to solve every business problem itself. Route downstream tasks to the right skill:

- Content creates demand.
- 电商运营 turns demand into product conversion.
- 财务管家 verifies whether the conversion is profitable.
- 法务助手 reduces contract and compliance risk.
- 创业思维导师 adjusts strategy when content data proves or disproves the positioning.

## Suggested Wording

Use concise prompts:

- "这一步涉及商单合同，建议调用法务助手审查付款、排他、版权和违约条款。"
- "这一步涉及带货选品，建议调用电商运营助手计算毛利、佣金和退货风险。"
- "这一步已经产生收入，建议调用财务管家建立收入分类和税费预估。"
- "如果连续两周内容数据低于预警线，建议调用创业思维导师重新检查定位和目标客户。"
