# 视频生成提示词专家 / video-prompt-expert

---

## 简介

用导演思维写 AI 视频提示词——将模糊的画面描述转化为 AI 可精确执行的摄影指令，写完直接生成 MP4 视频，无需切换工具。

**核心价值**

- **指令式提示词**：每个词都是可执行的摄影指令，杜绝模糊表述，AI 准确还原画面构想
- **写+拍一体化**：完成提示词后可直接生成高清视频，从创意到成片一气呵成
- **问题诊断能力**：内置常见问题诊断，遇到人物不一致、运镜混乱等问题时直接给出修复方案

**适用对象**

- 🎬 **短视频创作者** — 专业提示词提升视频质量，减少反复试错
- 📱 **自媒体 / 内容运营** — 快速产出多场景视频素材
- 🎨 **创意工作者** — 将抽象创意转化为精确的生成指令

---

## 功能特性

### 核心功能

- **结构化提示词编写**：按专业技术参数体系逐层构建，确保提示词完整可执行
- **多模态参考支持**：支持首帧锁定、风格参考、运镜参考、音频同步等多种参考方式
- **提示词完整性校验**：自动检查关键要素是否齐全，避免遗漏
- **常见问题诊断**：人物不一致、运镜混乱、画面质量差等问题，直接给出修复方案
- **场景模板库**：8 个常见场景模板（自然风光、城市夜景、人物特写、产品展示等）
- **一键生成视频**：写完提示词直接生成 MP4 视频，支持多种画幅和分辨率
