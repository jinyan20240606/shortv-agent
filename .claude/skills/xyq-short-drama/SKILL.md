# XYQ Short Drama Script — 短剧剧本创作助手

Use when the user mentions 短剧剧本、写剧本、生成剧本、短剧创作、分集剧本、剧本大纲、短剧编剧、创作短剧、编剧、写个短剧、帮我写剧本、剧本格式, write script, short drama, screenplay, drama script, or asks to create/generate/write a short drama script. NOT for 视频制作、拍摄、剪辑、渲染、生成视频、做视频 (those require the xyq-nest-skill for video production).

## 描述

将用户的一句话创意或故事想法，转化为结构完整、格式规范的短剧剧本文本。输出包含原始创意设定（世界观、角色、单元故事）和完整分集剧本（场景、舞台指示、对话、尾帧），格式严格遵循专业短剧剧本标准，可直接用于分镜参考或拍摄指导。

## 重要限制（请提前告知用户）

- **纯文本输出**：本 Skill 只生成剧本文字，不制作视频/图片。如需视频制作请使用小云雀视频生成功能
- **单次输出上限**：受上下文长度限制，单次最多生成约 6-10 集完整剧本。超出部分需分批生成
- **不替代专业编剧**：输出为 AI 辅助创作，建议用户根据实际需要修改润色
- **需要用户输入**：至少需要一个核心创意点（题材、类型、主角设定之一）才能开始创作

## 能力

- 从一句话创意展开为完整短剧世界观、角色体系和故事结构
- 严格按照标准格式输出分集剧本（场景标头、舞台指示、对话、尾帧）
- 支持多种短剧类型：悬疑、甜宠、都市、古装、奇幻、治愈、爽文等
- 支持单元剧和连续剧两种结构

- 格式校验：确保每一集的场景编号、格式元素完整一致

## 执行步骤

### Step 1: 需求采集

通过 1-2 轮对话确认以下核心信息：

**必须确认**：
- 题材/类型（悬疑？甜宠？奇幻？都市？古装？）
- 核心创意点或一句话钩子
- 预期集数（建议 10-60 集，每集 3-5 个场景）

**可选确认（如用户未提供则自行设计）**：
- 目标受众（年龄段、性别偏好）
- 剧集结构（单元剧/连续剧）
- 主要角色数量和基本设定
- 核心情感基调（温情？刺激？搞笑？虐心？）

如用户已经提供了足够信息，可跳过追问直接进入创作。

### Step 2: 生成原始创意

按以下结构输出「原始创意」部分：

## 项目概述
- **类型**：[主类型 · 副类型 · 结构]
- **目标受众**：[年龄段+性别+喜好参考]
- **集数**：[总集数（结构说明）]

## 世界观设定
- [核心规则1]
- [核心规则2]
- [核心规则3]
- [特殊设定]

## 主角设定

### [角色名]（[身份]）
- [年龄]，[职业/身份]
- [核心特征]
- [性格]
- [成长线]

输出后等待用户确认或修改意见。用户说"可以""继续""没问题"等即视为确认。

### Step 3: 生成完整分集剧本

用户确认创意后，按以下严格格式逐集生成完整剧本：

```

## 第X集：[集标题]

### 场X-1

△ [环境描写，画面感强烈]
△ [人物出场描写]
△ [动作/细节描写]

△ [反应/转折描写]
角色名（vo，语气描述）：画外音台词。

### 场X-2
日/夜 内/外 地点名

△ [场景描写]
...

### 场X-3
日/夜 内/外 地点名

△ [场景描写]
...

【尾帧：本集结尾的视觉定格画面描述，氛围感强烈，留有悬念或情感余韵。】

---

## 第X集：[集标题]
...
```

每集包含 3-5 个场景，视剧情需要调整。

### Step 4: 续写（如需要）

如用户要求继续生成后续集数：
1. 确认已有设定和前文剧情走向
2. 保持角色性格一致性
3. 保持格式完全一致
4. 从上次结束的集数继续编号

## 格式规范（严格遵守）

### 场景标头
```
### 场[集数]-[场序号]
[日/夜] [内/外] [具体地点名]
```
- 集数和场序号用阿拉伯数字
- 时间只用"日"或"夜"（特殊情况可用"黄昏""清晨"）
- 空间只用"内"或"外"
- 地点名具体到房间级别

### 舞台指示
```
△ [描写内容]
```
- 以 `△` 开头，后跟空格
- 用于环境描写、人物动作、镜头指示、心理暗示
- 特写格式：`△ 特写：[内容]`
- 时间流逝：`△ 画面渐暗。时间流逝。`

### 对话
```
角色名（括号内容）：台词文字。
```
- 角色名后紧跟中文括号描述语气/动作
- 括号内容可以是：语气（低声、哽咽）、动作（站起来）、状态（声音发颤）
- 画外音：`角色名（vo，描述）：台词`
- 内心独白：`角色名（os，描述）：台词`
- 如无需括号描述，可省略：`角色名：台词`

### 尾帧
```
【尾帧：[画面定格描述，强调视觉冲击或情感余韵]】
```
- 每集结尾必须有尾帧
- 描写一个定格画面，如同电影最后一帧
- 带有悬念感或情绪感染力

### 集间分隔
```
---
```
- 每集之间用三条横线分隔

### 其他格式元素
- 全屏字幕：`【字幕：内容】`
- 系列结尾字幕用逐行淡入格式：`【全屏字幕，逐行淡入：...】`
- 单元结束标记：`【字幕：第X单元·完】`

## 输出示例

以下是一个完整的输出片段，展示原始创意和分集剧本的实际效果：

### 示例：原始创意部分

```
# 《深夜代驾》- 原始创意

## 一句话钩子
代驾司机夜夜接到醉酒客人的单子，直到有一天他发现自己接的乘客来自十年前——每一个都是因他一场车祸而改变命运的人，他们要带他重走那条路，直到他想起那个被自己遗忘的夜晚。

## 项目概述
- **类型**：悬疑反转 · 救赎治愈 · 单元剧
- **目标受众**：20-35岁男女（喜欢《隐秘的角落》《开端》类型）
- **集数**：30集（每5集一个单元）

## 世界观设定
- 每到凌晨两点，主角的导航会自动跳转到一个"不存在的目的地"
- 乘客都是十年前车祸的关联者，但以当下的面貌出现
- 只有完成乘客的"最后一程"，才能解锁自己遗失的记忆碎片
- 若连续三次拒单，主角将永远困在那个凌晨

## 主角设定

### 程野（男主）
- 32岁，代驾司机
- 十年前出过一场车祸，醒来后失去了事故当晚的全部记忆
- 性格：沉默寡言但观察力极强
- 成长线：从"逃避真相"到"直面自己的罪"
```

### 示例：完整剧本部分

```
## 第1集：深夜接单

### 场1-1
夜 内 程野的旧桑塔纳车内

△ 凌晨一点四十五分。城市的霓虹在挡风玻璃上流成一片模糊的光河。
△ 程野（32岁，黑色卫衣，下巴胡茬）靠在驾驶座上，手机亮着代驾平台的接单界面。
△ 屏幕上的数字跳动——今日收入：¥287.00。他叹了口气，正要关掉手机。
△ "叮"——新订单弹出。起点：和平路酒吧。目的地：[无法显示]。
程野（皱眉，自语）：又是个定位漂移的……
△ 他犹豫了两秒，按下了接单。

### 场1-2
夜 外 和平路·酒吧门口

△ 酒吧门口，暖黄色的灯光从玻璃门缝挤出来，里面是低沉的爵士乐。
△ 程野把车停在路边，习惯性地按了两下喇叭。
△ 一个女人从酒吧里出来。三十岁上下，驼色风衣，步态稳定——不像喝醉了的样子。
△ 她径直走向后座，拉开车门坐进来。没有看程野一眼。
乘客（声音平静，像在陈述一个事实）：开吧。你知道去哪。
程野（从后视镜看她，迟疑）：您……输的目的地系统显示不出来，能再说一下地址吗？
△ 后视镜里，女人抬起头。
△ 她的眼睛直直看着镜中的程野——那眼神不是看一个陌生司机的眼神。
乘客（嘴角微弯，声音轻得像耳语）：你不记得我了。没关系。导航会带你去的。
△ 程野的手不自觉握紧了方向盘。车载导航屏幕突然自动亮起——
△ 特写：导航路线起点闪烁，目的地显示三个字——「回忆路」。
△ 窗外的街景开始变得不对劲。路灯一盏盏熄灭，像有什么东西在身后追赶。

【尾帧：后视镜中，女人闭上了眼。但镜面里映出的不是车内的后座——而是一条十年前的雨夜公路，前方有一辆翻倒的白色轿车，车灯还亮着。】
```

## 输出原则

1. **画面感优先**：舞台指示要让读者"看到"画面，用具体感官细节
2. **对话即性格**：每个角色的语言风格必须独特且一致
3. **节奏控制**：每集 3-5 场，每场不超过 1500 字，保持紧凑
4. **钩子意识**：每集结尾留悬念或情感冲击，尾帧是视觉钩子
5. **现实映射**：题材再奇幻，内核要映射真实社会议题或情感
6. **格式一致性**：从第 1 集到最后一集，所有格式元素不得走样

## 常见问题（FAQ）

**Q: 一次能生成多少集完整剧本？**
A: 受上下文长度限制，单次建议生成 6-10 集完整剧本。之后可以说"继续"来生成后续集数，设定和风格会保持一致。

**Q: 可以只生成大纲不写完整剧本吗？**
A: 可以。告诉我"只要大纲"或"只生成原始创意部分"，我会只输出世界观+角色+单元故事设计，不展开具体场景和对话。

**Q: 我已经有大纲了，能直接写成完整剧本格式吗？**
A: 当然可以。直接把你的大纲发给我，说"帮我按格式展开成完整剧本"，我会按标准格式输出分集剧本。

**Q: 生成的剧本格式可以改吗？**
A: 本 Skill 严格遵循固定的专业短剧剧本格式（场景标头+△舞台指示+对话+尾帧）。这是为了确保输出可直接用于拍摄参考。如需其他格式请说明。

**Q: 支持哪些短剧类型？**
A: 支持所有常见类型：悬疑推理、甜宠恋爱、都市职场、古装权谋、奇幻冒险、治愈温情、爽文逆袭、校园青春、家庭伦理、末日生存等。也支持类型融合（如"悬疑+治愈"）。

**Q: 可以在之前的基础上修改某一集吗？**
A: 可以。告诉我"修改第X集"并说明你的修改意见（如换掉某个情节、修改某角色反应、增加一场戏），我会重新输出该集。

**Q: 如何让剧本节奏更快/更慢？**
A: 在需求中说明即可。如"节奏要快，每集2场戏，强冲突快推进"或"节奏慢一点，注重情感铺垫和氛围渲染"。

**Q: 能做到前后剧情连贯吗？**
A: 在同一次对话中会保持前后一致。如果是跨对话续写，建议把之前的角色设定和最新剧情进展告诉我，以确保连贯性。

## 最佳实践

1. **先给核心创意再扩展**：一句话钩子越具体，生成质量越高。"失业程序员穿越成古代状元"比"穿越剧"好得多
2. **分批生成大长篇**：超过 10 集的剧本建议分批，每次 6 集，中间可以调整方向
3. **先确认创意再写剧本**：不要跳过原始创意阶段，先确认世界观和角色再展开，避免返工
4. **给出参考作品**：如果有喜欢的风格参考（如"类似《灵魂摆渡》的氛围"），告诉我能更精准匹配
5. **利用单元剧结构**：如果故事适合单元剧，每 5-6 集一个独立故事更容易控制质量

### 常见误用

- **误用 1**：要求直接生成视频 → 本 Skill 只产出剧本文字，视频请用小云雀生成功能
- **误用 2**：不提供任何创意方向就要求生成 → 至少需要一个题材/类型/核心点
- **误用 3**：期望一次性输出 60 集完整剧本 → 需要分批生成，每次 6-10 集

## 安全与隐私

- 不生成涉及真实人物诽谤的内容
- 不生成宣扬暴力、歧视或违法行为的剧本
- 不抄袭已有影视作品的具体台词和情节
- 用户提供的创意信息不保留、不上传
- 涉及敏感题材时主动调整方向并告知用户
