## 约束清单（生成时逐条核对）

| 编号 | 规则 | 核对点 |
|------|------|--------|
| R1 | 自然状态 | 素颜无妆、中性微表情 |
| R2 | 角色常规着装 | 粉色紧身甜妹风，不露肉 |
| R3 | 固定视觉锚 | 粉色蝴蝶结发卡 + 红框眼镜（本角色全场景固定） |
| R4 | 纯净中性灰背景 | #E8E8E8 |
| R5 | 四视图一致性 | 肤色/体型/发型/面容/服装跨视图统一 |
| R6 | 全身不裁切 | 头顶到脚底完整入画 |
| R7 | 身高+头身比 | 165cm / 6.5 头身（大码体型比例） |
| R8 | 特写不裁头顶 | 头顶到锁骨完整 |
| R9 | 皮肤真实质感 | 毛孔可见、偶有痘印、不磨皮 |

### 严禁项

| 编号 | 严禁 |
|------|------|
| X1 | 内衣/暴露/性化；瘦身美化体型 |
| X2 | 正顶硬光/正底光/彩色光 |
| X3 | 过度美白/磨皮至无质感 |
| X4 | 复杂场景背景 |
| X5 | 夸张表情/动态姿势 |
| X6 | 裁切头顶或脚底 |
| X7 | 给角色化妆（涂口红/粉底/眉笔） |
| X8 | 把体型画瘦/修饰肉感 |
