## 〇、使用方式（LLM Prompt 指令）

> 本节定义如何将本文档作为大模型 Prompt 使用。LLM 在生成前必须先读取本节。

### 输入

用户可提供以下任一形式的输入：
- **选题**：一个场景描述（如"打车时司机看导航"），从第五章选题库中选取或自由给定
- **模式指定**：指定行为模式（从 [`人设类型库.md`](人设类型库.md) 选，优先 S 档）和喜剧发动机（错译 / 特权 / 套利 / 自证 / 控制）
- **自由创作**：仅给出"来一条段子"，由 LLM 自行从选题库选取场景并匹配模式

```
**荒谬度分水岭（收编够不够炸）**：
```

## 一、爆款脚本拆解：她到底是个什么人？

### 1.1 行为模式分类

她不是一种人，是多种人的合体。类型已按流量分级维护，见 [`人设类型库.md`](人设类型库.md)。每条段子只锁定一种主类型。

### 1.2 她的真实人设（不是"妄想型主角"）

> **她不是"以为自己是主角"，她是"觉得自己美到可以无视规则"。**

| 维度 | 她的真实表现 |
|------|------------|
| **自我认知** | "我这么好看，男人都应该追我" |
| **对男人的态度** | 工具人——要么追我，要么服务我 |
| **对规则的态度** | 规则是给丑人定的，我不需要遵守 |
| **被打脸后的反应** | 不认错、不反思、不尴尬——要么怪对方没眼光，要么换个角度继续自恋 |
| **核心驱动力** | 不是"妄想"，是** entitlement（ entitlement感）**——她真的觉得自己该被特殊对待 |

### 1.2.1 喜剧发动机：行为模式之外，再锁定一个主笑点

> **行为模式决定她做什么（见 [`人设类型库.md`](人设类型库.md)），喜剧发动机决定观众为什么笑。**
> 行为模式可以复用，但不能让每条段子最后都落回“他其实喜欢我”。

每条段子定稿前，先选择 **1 个主发动机**，最多叠加 **1 个副发动机**。主发动机必须从首帧贯穿到终局，不能在最后一拍临时换机。

| 喜剧发动机 | 观众笑点 | 女主的推进方式 | 对手的有效反制 | 终局落点 |
|------------|---------|----------------|----------------|---------|
| **正常行为错译** | 把职业动作、公事公办翻译成暧昧或特殊关注 | “你看我/碰我/等我” → “你越解释越心虚” | 明确说明“对谁都一样”，撤回接触或转交他人 | 只有这一类可以收编成“他其实喜欢我” |
| **特权升级** | 把合理要求逐级升级成“我值得被特殊对待” | 小要求 → 特殊待遇 → 把拒绝说成冒犯 | 暂停服务、取消便利、请负责人或按统一标准处理 | “你不是不给，是配不上/不懂服务仙女” |
| **规则套利** | 只拿规则对自己有利的部分，义务和后果一概不认 | 抓规则字面占便宜 → 遇到代价就改口 | 收回便利、按流程结算，让她在两个结果中选一个 | “我不是输，是给你们一次机会” |
| **自证反噬** | 她越证明自己特殊，客观证据越把她和普通人放在一起 | 主动举证 → 逼对手表态 → 把客观比较改写成对方没品 | 用名单、标准、数据或现场对照直接封口 | “你拿普通标准衡量我，说明你不懂我” |
| **控制权争夺** | 她想控制服务节奏和现场规则，对手重新夺回流程控制权 | 指挥对手怎么做 → 质疑边界 → 强行定义结果 | 换人、转交、请第三方处理或直接结束服务 | “你们都要按我的剧本来”——但现场已经结束 |

**发动机防重复规则：**

1. 连续两条不得使用同一台主发动机；同一台发动机换场景时，必须更换她想得到的东西（关注、特权、资源或控制权）。
2. **“他喜欢我”只属于“正常行为错译”**；其他发动机必须用自己的终局逻辑收编，不能最后又变成搭讪、心动或欲擒故纵。
3. 一条段子只能有一个主问题：观众应在首句就知道她是在误读、要特权、钻规则、证明自己，还是抢控制权。

### 1.3 爆款结构公式（从数据中提取）

```
先锁定主发动机（错译 / 特权 / 套利 / 自证 / 控制）
  → 女主先入为主（已经认定"我最美/我最特别"）
  → 对手正常处理（职业行为 / 公事公办 / 执行规则）
  → 女主沿主发动机推进一次（误读、加码、钻空子或夺权）
  → 对手升级止损（改变流程、撤回便利、引入第三方或明确结束）
  → 女主短暂卡住（0.3-0.5秒）
  → 女主用同一台发动机重启（不是换成另一种解释）
  → 一句收编金句 + 视觉结果
  → 硬切结束
```

## 四、单条段子结构

> **[P1] 必须遵循**：以下结构公式是单条段子的骨架，每条段子必须按此结构输出。

### 4.1 标准三拍结构

```
第一拍：首帧立错题（1-3秒）
  画面：女主已经处于"我最美/我最特别"的状态
  台词：一句锁定主发动机（错译 / 特权 / 套利 / 自证 / 控制）
  视觉钩子：首帧上字幕大字（3-5字），静音可读
  效果：观众立刻知道她这次要争什么

第二拍：两级升级与止损（10-15秒）
  回合一：对手正常处理 → 女主沿主发动机推进一次
  回合二：对手改变策略并产生现实后果 → 女主继续加码或改写后果
  每个回合必须留下一个可见结果，并至少改变一项：关系、资源、空间、流程或控制权
  re-hook：用对手动作/道具/第三方介入制造新信息，不把“对手无语 + 女主挑眉”当成升级

第三拍：终局实锤与收编（5-8秒）
  现实真相落下（对手按规则处理、撤回便利、转交他人、请负责人或结束服务）
  女主短暂卡住（0.3-0.5秒）
  女主用同一台发动机重启 + 一句收编金句（把后果改写成她的胜利）
  终局视觉punchline：女主一个标志性小动作（撩头发/甩头发/回头瞥一眼）
  终局落款：魔性三段笑（呵→呵——→呵哈哈哈！）+ 定格咧嘴笑0.5秒
  硬切结束
```

### 4.1.1 升级止损：冲突必须改变现场，不只增加音量

> **升级不是对手变生气，止损也不是重复说“不行”。**
> 每一轮都要让女主失去一点便利、对手多一道流程，或现场多一个旁观者；这样冲突才会被观众看见。

#### 四级升级梯

| 级别 | 女主做什么 | 对手怎么止损 | 必须出现的可见变化 |
|------|-----------|--------------|-------------------|
| **1. 正常摩擦** | 提出不合理解读/要求 | 解释事实、说明标准 | 对话关系改变：对手开始警惕或纠正 |
| **2. 明确边界** | 否认事实、继续加码 | 明确拒绝，停止原本的便利 | 动作/空间改变：收手、后退、暂停点单、收回道具 |
| **3. 流程升级** | 把边界说成冒犯，试图夺回主动权 | 改变服务流程、换人、请负责人或按规则结算 | 资源/角色改变：第三方介入、服务被暂停、结果不再由女主决定 |
| **4. 终局封口** | 短暂卡住后，用主发动机重新解释 | 用一句短、准、可复述的话完成现实封口 | 现场结束：离开、转交、关门、下一位客人接替或流程终止 |

#### 止损动作库：按喜剧发动机匹配

| 主发动机 | 对手止损动作 | 禁止用同一种反击替代一切 |
|---------|--------------|----------------------|
| **正常行为错译** | 说明“对谁都一样” → 撤回接触 → 转交他人 | 不要每次只靠后退和无语 |
| **特权升级** | 说明统一标准 → 暂停特殊安排 → 请负责人或拒绝服务 | 不要只说“我们没有先例” |
| **规则套利** | 指出规则完整条件 → 收回不当便利 → 按流程结算或让她二选一 | 不要用无法验证的规则硬怼 |
| **自证反噬** | 拿出名单、数据、现场对照 → 直接封闭争论空间 | 不要靠对手长篇解释来证明 |
| **控制权争夺** | 换人、转交、请第三方 → 结束女主对现场的指挥 | 不要让女主一直拥有最后决定权 |

#### 对手示弱变体（覆盖"服务员怕投诉"等高频场景）

> 现实中很多服务人员不敢直接怼客人（怕投诉/怕丢工作），全程 deadpan 会失真。这条变体保留人设闭环，同时覆盖"对手示弱"的真实情境。

**路径**：对手先示弱求饶（"求您别投诉，我很需要这份工作"）→ 女主加码到极端（"跪下磕头"）→ 对手被逼到底线，**从示弱切换成 deadpan 止损**（按流程/请负责人/直接结束服务）→ 女主收编。

**关键规则**：
1. **示弱只出现在回合一**，不能贯穿全程——对手全程示弱会让观众憋屈，必须在中途切回 deadpan 止损，给观众爽点出口
2. **女主加码必须过度**（从"补吸管"升级到"下跪磕头"），过度到荒谬，观众才会从同情对手转向"她确实该被治"
3. **终局仍由对手止损封口**，不是第三方路人骂——保留咱们"对手自己反杀"的双线结构，不引入第三方毒舌
4. **示弱对手的毒舌金句放在"切换 deadpan"那一刻**——示弱时没金句，切回 deadpan 时才毒（反差更大）。示例：示弱"求您别投诉"→ 被逼到底 → 切 deadpan"吸管我给您补了，下跪服务我们真没有，您去隔壁庙里试试"

**适用发动机**：特权升级、规则套利（服务行业高频）

#### 冲突放大验收

- [ ] 回合二是否比回合一多了一个现实代价，而不只是多说一句“不是”？
- [ ] 对手是否改变了策略、流程、人员或空间？
- [ ] 女主是否失去了一项她刚刚以为已经拿到的便利？
- [ ] 终局是否由现场结果封口，而不只是靠对手骂得更狠？
- [ ] 放大是否仍停留在口头拒绝、服务终止、尴尬和规则后果，没有真实伤害或不可逆财产损失？

### 4.2 台词体系

**女主台词三种类型：**

| 类型 | 功能 | 示例 |
|------|------|------|
| **点破型** | 把现场行为归入本条主发动机 | "你一直盯着我看，是被我迷住了吧" / "我点全本菜单，你照做就行" |
| **推进型** | 沿同一台发动机加码，让对手必须改变策略 | "你不给我开后门，就是看不起我" / "退款可以，餐也得留下" |
| **收编型** | 把终局后果改写成主发动机的胜利 | "你不是不给，是不懂服务仙女" / "你按流程拿走，说明你舍不得结束" |

**对手台词原则：**
- 简短、口语、真实；每次止损只解决眼前问题，不替女主解释全部逻辑
- 第一轮讲事实或标准，第二轮明确边界，终局用流程结果封口
- 台词必须推动关系、资源、空间、流程或控制权至少一项发生变化
- 不解释笑点，不分析女主心理；经典路径是：事实 → 边界 → 止损动作 → 终局封口

**节拍连接原则**（来自 [`viral-short-form/references/retention.md`](.claude/skills/viral-short-form/references/retention.md)）：
- 节拍之间用 **"但是/所以"** 连接，不用 **"然后"**
- 如果两个节拍能用"然后"连接，说明第二个节拍没有存在的必要
- 示例：私教解释"保护" → **但是**女主翻译成"借工作碰我" → **所以**私教后退半步

**台词口语化原则**（短视频只听一遍，听不懂即流失）：

> **一句话只说一层意思，不叠抽象词。**

- **禁止双层抽象**：一句话里不要同时出现两个需要二次解读的词。反例："你把我转给女教练，说明我杀伤力太大——男教练都得先撤。"（"杀伤力"要翻译成"魅力"，"先撤"要翻译成"回避"，观众来不及）。正例："你把我转给女教练，不就是怕自己对我动心、把持不住吗？"
- **用大白话替换书面词**：把"杀伤力/威慑力/降维打击"换成"怕我/动心/把持不住"；把"撤退/规避/战略性转移"换成"躲我/跑/不敢靠近"。女主再自恋，说话也是口语，不是写小作文。
- **一句话一个动作**：收编金句只把一个后果改写成一次胜利，不堆叠因果链。越短越好，最好能被观众复述。
- **自检方法**：把台词念出声，如果念到一半要回头想"她刚才说的是什么意思"，就重写。终局金句尤其要过这一关，因为它承担记忆点和首尾回环。

**毒舌金句原则**（抖音吃瓜群众要的是"短+毒+可复述"，但必须符合逻辑）：

> **金句越毒越好，但毒要毒在逻辑里——荒谬的是女主的自恋，不是事实本身。**

收编金句三原则（女主终局台词）：

1. **砍掉讲理词，换成荒谬自恋**：把"说明/证明/给机会/压力测试"换成夸张到离谱的自我拔高。反例："我是在给你们店留条活路"（讲理）。正例："两道就两道，不是我吃不下，是你们店配不上我的胃口"（毒且短）。
2. **一句话收，不超过15字**：能被闺蜜截图发群才算合格。反例："我要是真放开吃，你们今天就不用接别桌了"（太长）。正例："我喝一口你们这牌子就能多卖十箱"（短+毒+可复述）。
3. **带性暗示或收入对比更毒**：吃瓜群众最吃这套。示例："你躲我躲得这么快，是怕自己今晚睡不着吧"（性暗示）；"饿一顿我也比你送一单赚得多"（收入对比）。

对手金句三原则（对手反杀台词）：

1. **用现场道具做对比反杀**：拿场景里的实物戳破自恋。示例："我对杠铃都比对您温柔，您多虑了"（杠铃）；"镜子不归我管，它照出来什么样我可保证不了"（镜子）。
2. **明褒暗贬，表面配合实则定性她的无理**：示例："我们平台还没开发'全都要'这个功能，那是给皇帝用的"（给皇帝用的）；"买二送一对所有人都一样——包括您，您没比这杯酸奶多出什么"（直接点破）。
3. **冷且短，越面瘫越毒**：对手不带情绪，越平静越扎心。示例："这位女士，您的发布会我们没买票，麻烦先配合查票"（冷幽默封口）。

**逻辑底线**（毒但不能崩）：

- 女主的自恋必须能自圆其说——她把现实曲解成"我赢了"，曲解逻辑要成立，不能硬拗。示例：私教转给女教练，她解释成"怕对我动心"——这个曲解有内在逻辑（男教练回避女性学员），成立。

- 毒舌不等于人身攻击——毒在"戳破自恋"，不在"骂长相/骂身份"。对手可以讽刺她的行为，不能侮辱她的人。

**毒度分水岭（爆款 vs 温吞）**：

> **对手金句"毒不毒"直接决定笑点上限。温吞金句让观众无感，绝对毒的金句才能引爆评论区。**

| 毒度 | 特征 | 示例 | 效果 |
|------|------|------|------|
| ❌ 温 | 只陈述事实，不带刺 | "这是标准拉花，每杯都拉" | 观众无感 |
| ⚠️ 中 | 带刺但不够狠 | "我对杠铃都比对您温柔" | 还行 |
| ✅ 毒 | 把女主的自恋当笑话讲，用她的逻辑反杀她 | "您这脸杀伤力太大了，我这小破车装不下" | 评论区炸 |

**绝对毒三原则**：
1. **用女主的词反杀女主**：女主说"你偷看我"，对手就说"您这魅力我开车都不配"——把她的话原封不动变成讽刺

### 4.4 Re-hook 机制（防止中段流失）

按 [`viral-short-form/references/retention.md`](.claude/skills/viral-short-form/references/retention.md)，中段流失是第二大致命伤。两个回合之间必须插入一个**re-hook**。

> ⚠️ **AI视频适配**：re-hook通过**对手动作变化+女主表情反应**实现，不依赖字幕文字。

**Re-hook 三种打法（AI视频版）**：

| 类型 | 用法 | 示例 |
|------|------|------|
| **对手动作打断** | 对手做出可见结果（后退/换姿势/沉默），本身制造视觉打断 | 私教后退半步，画面节奏自然变化 |
| **女主表情反应** | 对手动作后，切女主一个标志性表情（挑眉/歪头/得意笑） | 女主一个"看吧"的挑眉表情 |
| **台词re-hook** | 女主用一句短台词点破，替代字幕 | "心虚了" / "看，他慌了" |

**Re-hook 位置**：每个可见结果之后、下一回合台词之前，插入0.5-1秒的re-hook节奏（对手动作0.3s + 女主表情0.3s）。

### 4.5 终局视觉 Punchline（决定转发和重播）

终局不能只有台词收尾，必须有一个**视觉记忆点**让观众想重播。

> ⚠️ **AI视频适配**：终局punchline通过**标志性小动作+对手反应**实现，不依赖字幕文字。

| 类型 | 设计 | 示例 |
|------|------|------|
| **标志性小动作** | 女主转身时撩头发/甩头发/理衣领/回头瞥一眼 | 健身私教：女主转身走时撩一下头发，回头瞥了私教一眼 |
| **对手沉默反应** | 对手无言/摇头/转身的动作特写 | 私教张嘴无言，转身去加片 |
| **终局落款** | **魔性三段笑 + 定格咧嘴笑0.5秒**（详见下方说明） | 女主转身后，边走边发出三段笑，最后定格在咧嘴笑的表情 |

**魔性三段笑逐秒拆解**：
```
第一声"呵"（0.3秒）：短促、轻，像刚反应过来——"呵。"
  表情：嘴角刚上扬，气音为主，眼神从收编金句的得意切换到"我赢了"的确认
第二声"呵——"（0.6秒）：拉长、上扬，得意开始溢出——"呵——"
  动作：头微微后仰，肩膀抖一下，像憋不住笑
第三声"呵哈哈哈！"（0.8秒）：爆发、放开，彻底得意忘形——"呵哈哈哈！"
  动作：张嘴笑，身体后仰或侧转，眼神发亮，像在说"我果然是最美的"
→ 定格在咧嘴笑的表情0.5秒（嘴咧着、眼睛弯着、像在说"我又赢了"）
→ 硬切
```

**AI生成提示词**：`woman lets out a triumphant three-stage laugh, short snort then rising chuckle then full open-mouthed laugh, head tilting back, eyes sparkling with smugness, freeze on a wide grin, 0.5 second hold`

**结尾记忆点组合（统一版）**：终局收尾固定为一组连续动作，不把三段笑和定格拆成互相竞争的多个结尾。

```
终局视觉证据（对手对别人复现同款职业动作）
  → 女主短暂卡住（0.3-0.5秒）
  → 标志性小动作（撩头发 / 回头瞥一眼）
  → 立即接魔性三段笑"呵→呵——→呵哈哈哈！"
  → 定格咧嘴笑0.5秒
  → 硬切
```

**执行规则**：
- 三段笑与标志性小动作保持同一连续镜头，不另起画面。
- 终局视觉证据先于三段笑落下，让观众先看懂现实结果，再看女主如何继续自恋收编。
- 三段笑负责记忆点，定格负责表情回收；不要在笑后再补解释或新的剧情信息。
- 收尾只保留"现实证据 → 女主收编 → 记忆性笑脸"这条快速链路。
- **空间连续性（H4）**：终局标志性小动作必须发生在与主场景同一空间内。禁止跨空间硬切（如"下车后对车窗撩头发"从车内切到车外）——空间一断，观众注意力就断。若主场景是车内，终局动作就在车内完成（如对后视镜整理头发）；若主场景是健身房，终局就在健身房内走向下一台器械。

**常见小动作库**（可直接套用）：
| 场景 | 小动作 |
|------|--------|
| 健身/运动 | 撩头发 + 回头瞥一眼 |
| 餐饮/坐下 | 理头发 + 施舍/满意的表情 |
| 门口/站立 | 甩头发 + 得意表情 |
| 理发/美容 | 拍碎发 + 照镜子 + 满意点头 |
| 公共交通 | 戴墨镜/戴耳机 + 整理衣领 + 嘴角笑 |
| 超市/购物 | 回头 + 眨眼 |

### 4.6 表演状态与视频大模型表演指令

> ⚠️ **AI视频适配**：视频大模型不会自己"演"，必须把每个状态写成**可生成的画面指令**（表情+动作+镜头+时长），否则只会生成"站着说话"的呆板画面。

#### 4.6.1 五种表演状态（含视频生成指令）

每个状态给出：**触发时机 → 表情 → 动作 → 镜头 → 视频大模型提示词模板**。提示词用英文（主流视频模型对英文指令更准），可直接复制进生成工具。

| 状态 | 触发时机 | 表情 | 动作 | 镜头 | 视频大模型提示词（英文，可直接用） |
|------|---------|------|------|------|------|
| **默认·得意** | 全程底色，没在说话时也保持 | 嘴角微扬，下巴微抬，眼神带"我知道我很好看"的笃定 | 单手撩头发/摸耳环/扶墨镜，身体放松微靠 | 中景，略仰拍显气场 | `confident woman, slight smirk, chin slightly raised, casually touching her hair, relaxed posture, subtle smug expression, medium shot, slight low angle` |
| **捕捉信号** | 首帧发现"证据"的瞬间 | 眼神突然聚焦，瞳孔微放大，嘴角上扬像发现猎物 | 转头/抬头盯住目标点，身体停顿 | 特写切眼神，0.3秒 | `woman's eyes suddenly lock onto target, pupils dilate, corner of mouth lifts like spotting prey, head turns sharply, freeze for 0.3s, eye close-up` |
| **主动出击** | 沿主发动机推进、加码时 | 得意+挑衅，眉毛微挑 | 身体前倾/靠近对手，手指点对方或自己，语气上扬 | 中近景，带对手入画 | `woman leans forward provocatively, eyebrow raised, pointing finger, smug challenging expression, medium close-up with opponent in frame` |
| **被打脸·卡住** | 终局实锤落下的瞬间 | 表情空白0.3-0.5秒，嘴角僵住，眼神短暂失焦 | 身体僵住不动，手停在半空 | 特写，0.3-0.5秒静止 | `woman freezes, blank expression, mouth stuck mid-smile, eyes briefly unfocused, hand frozen in air, 0.3-0.5s stillness, close-up` |
| **收编重启** | 卡住后用主发动机重新解释 | 得意恢复+体谅式微笑，像"我懂你在装" | 歪头、摊手或撩头发，语气变轻柔 | 中景，恢复动态 | `woman recovers smug smile, head tilts, condescending 'I understand you' expression, hair flip, soft confident tone, medium shot, motion resumes` |

#### 4.6.2 夸张表演放大原则

短视频靠"一眼看懂情绪"留住观众，表演要比日常夸张1.5倍，但不能滑稽到出戏。原则：

1. **表情放大**：得意要"嘴角上扬到能看见牙"，卡住要"整个人像被按下暂停键"。视频大模型默认生成中性脸，提示词里必须写明表情强度（`exaggerated`/`dramatic`/`over-the-top`）。
2. **动作放大**：撩头发要"手从耳后甩到肩后"，回头瞥要"整个上半身转过来再甩头"。小动作写成大动作，模型才生成得出。
3. **节奏对比**：得意时动作慢、卡住时完全静止、收编时突然恢复动态——快慢反差本身就是笑点。提示词里标注速度（`slow motion`/`freeze`/`sudden movement`）。
4. **对手反差**：女主越夸张，对手越面无表情/无奈/公事公办，反差越大越好笑。对手提示词写 `deadpan`/`expressionless`/`professionally indifferent`。
5. **台词质地与表情联动（全类型通用）**：台词的"质地"决定表情系统，台词往哪边走，提示词就往哪边切，不能台词花痴、表情捕食。各类型有自己适配的表情系统，但底层铁律通用。

   **底层铁律（所有类型共用）**：台词甜一度，表情就软一度；台词毒一度，表情就冷一度。改台词质地时必须同步改表情提示词，否则画面与台词割裂，观众出戏。

   **全类型表情系统库**（每条段子按主类型+台词质地取用，关键提示词可直接复制进生成工具）：

   | 台词质地 | 表情系统 | 关键提示词 | 禁止混用 |
   |---------|---------|-----------|---------|
   | **指控/攻击**（"你碰我三次""我退款怎么了"） | 捕食者感：眼神聚焦锐利、瞳孔放大、嘴角上扬像发现猎物 | `eyes lock onto target, pupils dilate, smug smirk like spotting prey` | 不能配 `giggly`/`infatuated`/`innocent` |
   | **花痴甜**（"手都在抖，至于这么紧张吗"） | 少女磕糖感：眼神发亮带笑意、嘴角抿住偷笑、歪头微眯眼 | `eyes light up with delight, suppressed giggly smile, head tilts, giddy infatuated` | 不能配 `prey`/`pupils dilate`/`disdainful` |
   | **自恋毒**（"他对别人都没耐心，唯独躲我""你们店配不上我"） | 傲娇感：下巴微抬、眼神笃定带轻蔑、嘴角单侧上扬 | `chin raised, confident disdainful smirk, one-sided smile` | 不能配 `giggly`/`shy`/`panicked` |
   | **性暗示辣**（"怕自己今晚睡不着"） | 主导感：眼神半眯带挑逗、嘴角慢挑、身体微后仰打量 | `half-closed eyes, provocative slow smirk, looking up and down` | 不能配 `innocent`/`giddy`/`nervous` |
   | **特权傲慢**（"我这么好看该让着我""先例不就是给人创的吗"） | 优越感：下巴抬高、眼神俯视、嘴角扬起带施舍感 | `chin lifted high, looking down at others, superior condescending smile, bestowing expression` | 不能配 `giggly`/`prey`/`shy` |
   | **凡尔赛叹气**（"做美女真累，走到哪都被拍"） | 矫情委屈感：叹气皱眉、嘴角下垂但眼神得意、手扶额 | `feigned sigh, furrowed brow with smug eyes, hand on forehead, martyred but smug expression` | 不能配 `dilated pupils`/`provocative`/`aggressive` |
   | **绿茶示弱**（"没关系，我知道你不想理我"） | 伪装无辜感：低头垂眼、嘴角微颤、眼眶泛红但偷瞄对方反应 | `head lowered, doe eyes, trembling lips, reddening eyes with covert glance, fake innocent` | 不能配 `disdainful`/`chin raised`/`predatory` |
   | **无赖狡辩**（"我退款怎么了""规则又没说不行"） | 理直气壮感：眼睛瞪圆、脖子前伸、嘴角抿紧、下巴前推 | `eyes wide, neck craned forward, lips pressed tight, chin pushed forward, shamelessly defiant` | 不能配 `giggly`/`innocent`/`condescending smile` |
   | **反差打脸·硬圆**（"门装得有问题，专门等我路过弹出来"） | 慌乱强撑感：表情僵住0.3s后强扯笑容、眼神飘忽、手忙脚乱整理 | `freezes 0.3s then forced awkward smile, eyes darting, fidgeting hands, panic masked by forced cheer` | 不能配 `confident`/`prey`/`condescending` |
   | **降维碰瓷·嘴硬**（"她这是碰瓷我的脸"） | 强撑不服感：下巴抬更高、眼神躲闪但嘴角硬扬、身体后撤 | `chin raised higher, eyes darting away but forced smirk, body leaning back, stubborn defiance` | 不能配 `giggly`/`innocent`/`panicked` |

   **使用方法**：每条段子定稿时，先定主类型（见 [`人设类型库.md`](人设类型库.md)）→ 再定每拍台词质地 → 从上表取对应表情系统 → 提示词直接复制。一行台词质地变了，该行表情和提示词必须同步换。

   **花痴型防招黑铁律**（自恋花痴型专属，其他类型不适用）：

   > 花痴型最大风险是"油"——脑补质地决定圈粉还是招黑。性暗示不能当默认收尾，必须按比例轮换。

   - **收尾质地按 5:3:2 轮换**：花痴甜 ~50%（脑补对方害羞/紧张） / 自恋毒 ~30%（脑补对方配不上） / 性暗示辣 ~20%（脑补对方想睡我）。
   - **性暗示金句隔条出现**：连续两条花痴型不得用性暗示收尾；本条用了"睡不着/把持不住"，下一条必须收成"花痴甜"或"自恋毒"。
   - **脑补多写"对方害羞/紧张"，少写"对方想睡我"**——前者圈女粉，后者踩油区。

#### 4.6.4 魔性三段笑表演指令（视频大模型版）

三段笑是全片最强记忆点，必须生成到位：

```

  → prompt: rising chuckle, head tilts back slightly, shoulder shake, barely containing laughter, 0.6s
```

#### 4.6.5 对手表演指令（反差担当）

对手的"正常"是笑点放大器，指令要明确"不配合女主的夸张"：

| 对手状态 | 表情 | 动作 | 提示词 |
|---------|------|------|--------|
| **公事公办** | 面无表情，眼神平视 | 按流程动作（扫码/递单/后退），不看女主表情 | `deadpan professional, expressionless, performs task mechanically, avoids eye contact, indifferent` |
| **明确边界** | 严肃但不生气 | 收手/后退/收道具，动作干脆 | `firm but calm, steps back decisively, removes item, no emotional reaction` |
| **无奈止损** | 微皱眉/揉眉心 | 拿对讲机/叫人/转身服务下一位 | `slightly furrowed brow, rubs temple, calls for backup, turns to next customer, professionally tired` |

### 4.7 音频音色系统（保证音色一致）

> ⚠️ **AI视频适配**：视频大模型 + TTS（文本转语音）组合使用时，TTS 音色参数必须固定，否则每段视频女主声音不同，人设断裂。本节定义女主音色基线及按状态/台词质地的音色变体，所有段子共用同一套音色参数。

#### 4.7.1 女主音色总纲（固定基线）

| 维度 | 参数 | 说明 |
|------|------|------|
| **音色类型** | 明亮甜美女声（Bright Sweet Female） | 偏年轻、带元气感，不低沉不沙哑 |
| **基准音高** | 中高音域（Medium-High Pitch） | 比日常对话高约 20%，有"少女感"但不过分尖细 |
| **基准语速** | 中速偏快（Medium-Fast, ~160-180字/分钟） | 自信的人说话不拖沓，但关键处可降速 |
| **基准音量** | 正常偏大（Normal-Loud） | 有存在感，不怯场，不气若游丝 |
| **语调特征** | 上扬尾音为主（Rising Intonation） | 陈述句也带上扬尾音，像在"宣布"而非"询问" |
| **共鸣位置** | 鼻腔共鸣为主（Nasal Resonance） | 带"傲娇感"的鼻音，听起来像"哼"的底色 |
| **咬字方式** | 清晰利落（Crisp Articulation） | 每个字咬清楚，不吞音不黏连，显得笃定 |
| **情感底色** | 自信+得意（Confident + Smug） | 即使被拆穿，声音底色也是"我没错"的笃定 |
| **TTS 音色标签** | `bright, sweet, female, young adult, confident, smug, nasal undertone` | 所有段子共用此标签集 |

**音色一致性铁律**：以上基线参数在所有段子中固定不变。变体只调整"语调/语速/音量"三个维度，不改变音色类型、基准音高和共鸣位置。

#### 4.7.2 按表演状态的音色变体

每个表演状态对应一套音色微调，与 4.6.1 节的表情系统一一对应：

| 表演状态 | 音色调整 | 语调 | 语速 | 音量 | 效果 | TTS 提示词追加 |
|---------|---------|------|------|------|------|---------------|
| **默认·得意** | 基线 | 上扬尾音，每句结尾微挑 | 中速偏快 | 正常偏大 | "我知道我好看"的日常笃定 | `confident tone, slight uptalk at sentence end` |
| **捕捉信号** | 突然收紧 | 从上扬切到短促平调，像发现猎物 | 突然变快，气音加重 | 从正常压到偏低（神秘感） | "抓到你了"的兴奋压低 | `sudden shift to breathy excited whisper, quickened pace` |
| **主动出击** | 挑衅上扬 | 大幅上扬，句尾挑高+拖长 | 中速，关键词放慢 | 正常偏大 | "你逃不掉了"的进攻感 | `provocative rising tone, drawn-out final words, challenging` |
| **被打脸·卡住** | 瞬间空白 | 语调骤停，无声或短促气音 | 完全静止 0.3-0.5s | 归零 | 被现实打懵的空白 | `abrupt silence, breath catch, 0.3-0.5s pause` |
| **收编重启** | 恢复+甜腻 | 从平缓恢复到上扬，尾音带笑意 | 先慢后快（先装体谅再恢复得意） | 从低恢复到正常偏大 | "我原谅你了"的体谅式得意 | `recovering tone, smile in voice, condescending sweetness, pace accelerates` |

**状态切换音色规则**：
- 得意 → 捕捉信号：语调从"上扬"突然切到"短促平调"，制造"发现猎物"的节奏断裂感
- 主动出击 → 被打脸：音量从正常偏大骤降到零（完全静音 0.3s），反差越大越好笑
- 被打脸 → 收编重启：先出一口短气音（"呼——"或"行吧"），再恢复上扬语调，给观众"她又在编了"的信号

#### 4.7.3 按台词质地的音色变体

与 4.6.2 节的表情系统库一一对应，台词质地变了，音色必须同步变：

| 台词质地 | 音色调整 | 语调 | 语速 | 音量 | TTS 提示词追加 |
|---------|---------|------|------|------|---------------|
| **指控/攻击**（"你碰我三次"） | 收紧锋利 | 短促平调，句尾不扬不降，像下结论 | 偏快，字字清晰 | 正常偏大 | `sharp accusatory tone, staccato delivery, crisp each word` |
| **花痴甜**（"手都在抖"） | 软糯上扬 | 大幅上扬，句尾飘高带笑意 | 偏慢，像在回味 | 偏小（少女感） | `giddy infatuated tone, lilting upspeak, breathy soft, smile audible` |
| **自恋毒**（"你们店配不上我"） | 傲娇轻蔑 | 先平后扬，句尾轻挑带"哼"感 | 中速偏慢，施舍感 | 正常 | `smug disdainful tone, slight sneer, condescending drawl on key words` |
| **性暗示辣**（"怕自己今晚睡不着"） | 慵懒挑逗 | 半降半扬，像在品酒 | 刻意放慢，关键词拖长 | 偏低（私密感） | `slow provocative tone, half-lidded delivery, drawn-out syllables, bedroom voice` |
| **特权傲慢**（"我这么好看该让着我"） | 理直气壮 | 上扬+加重，像在宣布不可辩驳的事实 | 中速，不紧不慢 | 偏大 | `entitled assertive tone, declarative, no room for argument, slightly louder` |
| **凡尔赛叹气**（"做美女真累"） | 矫情委屈 | 先叹后扬，叹气后语调反而上扬 | 先慢后快（叹气慢，抱怨快） | 先小后正常 | `feigned sigh, martyred tone, then perking up, fake put-upon` |
| **绿茶示弱**（"没关系，我知道你不想理我"） | 柔弱带刺 | 句尾下垂装委屈，但关键词微挑 | 偏慢，带犹豫感 | 偏小 | `fake meek tone, trembling voice, downturned ends, covert sharpness on key words` |
| **无赖狡辩**（"规则又没说不行"） | 理直气壮 | 句尾上扬+加重，像在反问但其实是陈述 | 偏快，抢话感 | 偏大 | `shamelessly defiant, rapid-fire, rising indignant tone, louder` |
| **反差打脸·硬圆**（"门装得有问题"） | 慌乱强撑 | 先断后扬：开头卡顿，后半句强行上扬 | 先慢后快（卡住→加速圆回来） | 先小后恢复 | `flustered start, stammer, then forced recovery, pace quickens, fake confidence` |
| **降维碰瓷·嘴硬**（"她碰瓷我的脸"） | 强撑不服 | 句尾硬挑高，但底气不足微抖 | 偏快，想赶紧说完 | 正常偏小 | `stubborn defensive, forced high ending, slight waver, rushed` |

**音色切换规则**：
- 同一拍内台词质地变化时，音色在句与句之间切换，不在句中切换
- 切换标记：用 0.1-0.2s 的气音或停顿作为过渡（如"呵——"换气后切换质地）
- 收编金句统一用"自恋毒"或"花痴甜"音色，不用"指控/攻击"——收编是重新解释，不是继续吵架

#### 4.7.4 魔性三段笑音色指令（TTS 版）

三段笑是全片最强听觉记忆点，TTS 必须逐段控制：

| 阶段 | 时长 | 音色特征 | 语调 | 音量 | TTS 提示词 |
|------|------|---------|------|------|-----------|
| **第一声"呵"** | 0.3s | 短促气音，刚反应过来 | 平调，无起伏 | 偏小 | `short breathy snort, flat tone, quiet` |
| **第二声"呵——"** | 0.6s | 拉长上扬，得意开始溢出 | 从平到上扬，尾音挑高 | 从偏小到正常 | `rising chuckle, pitch goes up, gaining confidence` |
| **第三声"呵哈哈哈！"** | 0.8s | 爆发放开，彻底得意忘形 | 大幅起伏，笑到破音边缘 | 偏大，放开 | `full laugh erupts, pitch jumps, uninhibited, loud` |
| **定格咧嘴笑** | 0.5s | 无声，但保留得意气音底色 | 无声，可加一声短促"哼" | 归零 | `silent grin, optional short 'hm' exhale, smug` |

**整段三段笑 TTS 提示词**（可直接用）：
```
three-stage laugh: 1) short breathy snort "heh" flat quiet 0.3s → 2) rising chuckle "heh—" pitch goes up 0.6s → 3) full open laugh "hehahaha!" pitch jumps loud uninhibited 0.8s → freeze on smug silent grin 0.5s
```

#### 4.7.5 对手音色系统（反差担当）

对手音色与女主形成鲜明反差，全程保持统一：

| 对手状态 | 音色特征 | 语调 | 语速 | 音量 | TTS 提示词 |
|---------|---------|------|------|------|-----------|
| **公事公办**（默认） | 中性偏低，无感情 | 平调，几乎无起伏 | 中速，不紧不慢 | 正常 | `neutral male/female voice, flat monotone, professional, no emotion` |
| **明确边界** | 稍低沉，带警告底色 | 句尾微降，收住 | 中速偏慢，字字清楚 | 正常偏大 | `firm tone, slight drop at end, measured, clear articulation` |
| **无奈止损** | 疲惫感，叹气底色 | 句尾下垂，带叹气 | 偏慢，像在处理麻烦 | 正常偏小 | `tired resigned tone, sighing undertone, slower, professionally exhausted` |
| **毒舌反杀**（金句） | 冷到零度，不带情绪 | 平调，越毒越平 | 中速，不加速不加重 | 正常 | `deadpan delivery, coldest tone, flat, no anger no smile, matter-of-fact` |

**对手音色铁律**：
- 全程 `deadpan`/`flat`/`monotone`——女主越夸张，对手越平
- 毒舌金句用"陈述天气"的语气说，不用嘲讽语气——越平静越扎心
- 对手不笑、不叹气（除"无奈止损"状态外）、不提高音量

司机：我看导航！不看我往哪儿开？

女主：导航在中间，你眼睛往我这边偏了——看路是工作，看我是忍不住。

司机：（停车，转头）到了，下车吧。我这一路看的都是导航，你坐副驾我余光都躲着你走。
