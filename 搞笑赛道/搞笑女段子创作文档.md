## 〇·B、分镜表输出模式（供直接生成AI视频）

> **核心原则：按"段"不按"镜"**。当前 AI 视频模型（即梦/可灵/Runway/Sora）普遍支持单段 10s 连续镜头，因此分镜表按**一拍一段**合并，每段 ≤10s，整条段子 3 段即可覆盖 30s。**禁止拆成 6-7 个 3-5s 小镜头**——拼接次数多、易跳帧换脸、色调不一致。

### 合并原则

1. **一拍一段**：第一拍=段1(≤10s)、第二拍=段2(≤10s)、第三拍=段3(≤10s)，总 30s 左右
2. **re-hook 不单列**：re-hook 是段内节奏变化（对手动作+女主表情+短台词），并进所在段，不独立成段
3. **终局硬切保留**：第三拍末尾的硬切是设计好的收尾，不合并
4. **一致性锚复用**：每段开头复用同一套主体描述，模型不会换脸
5. **动作时序**：段内用 `first…then…finally…` 描述连续动作，模型能理解"这是一个连续镜头内的先后动作"

### 每段必含字段（AI视频 prompt 八件套）

每个段落的英文 prompt 必须整合以下要素：

| # | 要素 | 说明 | 搞笑赛道重点 |
|---|------|------|------|
| 1 | **主体 Subject** | 人物身份/服装/发型/特征，多段必须复用同一套词做一致性锚 | 女主视觉锚固定 |
| 2 | **动作链 Action chain** | 连续动词链描述(first crouching→smoothing→then looking up→finally roommate enters)，非静态 | ⭐核心笑点 |
| 3 | **微表情 Expression** | 眉/眼/嘴/下巴/视线五维分解，禁止只写happy/excited | ⭐反差核心 |
| 4 | **场景 Scene** | 地点/空间布局/背景/道具位置 | 道具是punchline载体 |
| 5 | **镜头语言 Camera** | 景别(close-up/medium/wide)+机位(eye-level/low/high)+运镜(static/push-in/pan) | 最易漏，必写 |
| 6 | **光影 Lighting** | 光源/明暗/色温/氛围(comedic tone) | — |
| 7 | **风格画质 Style** | realistic/cinematic/high detail/4k | — |
| 8 | **时长节奏 Duration** | 目标秒数+动作快慢(snappy/slow) | 对齐时长预算 |

**三个加分项**（搞笑赛道建议全带）：
- **多主体关系**：女主+对手同框时明确相对位置与谁主谁次
- **动作时序**：段内用 `first…then…finally…` 描述先后
- **负向提示 Negative**：见下方负向提示库，每段必带

### 分镜表模板

```
## 分镜表：[标题]

**总段数**：[N] 段 | **总时长**：[X]s | **视频模型**：[即梦/可灵/Runway/Sora]

| 段号 | 时长 | 景别/机位/运镜 | 画面(中·连续动作链) | 微表情(中·眉眼嘴) | 画面Prompt(EN·八件套整合·first…then…finally) | 台词/配音(逐句) | 音效 |
|------|------|---------------|------|------|------|------|------|
| 1 | 0-10s | 中景/eye-level/static | [一拍内的连续动作链] | [女主+对手全程微表情变化] | [整合八件套+动作时序的完整英文prompt] | [台词1] [台词2] | [环境音] |
| 2 | 10-20s | ... | [二拍内的连续动作链] | ... | ... | ... | ... |

```

### Prompt 一句话公式（LLM 拼 prompt 时套用）

```
[景别机位运镜] + [主体+服装(一致性锚)] + [动作链·first…then…finally] +
[女主微表情5维·全程变化] + [对手位置+反应表情] + [场景+关键道具] +
[光影+comedic tone] + [风格画质] + [时长节奏]
— Negative: [排除项]
```

### 负向提示库（每段必带，按模型语法微调）

```
deformed hands, extra fingers, distorted face, face morphing, 
identity change, extra people, floating objects, text, subtitles, 
watermark, blurry, low quality, warped limbs, unnatural motion
```

### 拆段五步法

1. 脑内按三拍搭好段子
2. 一拍=段1(≤10s)、二拍=段2(≤10s)、三拍=段3(≤10s)
3. 每段内用 `first…then…finally…` 描述连续动作链，re-hook 并进段内
4. 每段按八件套+三加分项拼 EN prompt，微表情查 [`4.6.1 微表情词库`](搞笑赛道/搞笑女段子创作文档.md:413)
5. 逐段核对时长之和 ≤ 30s，超了就精简台词或合并动作

## 〇·C、去 AI 味与真实感门禁（每条 S5 必过）

> **目标不是把故事写得更狠，而是让观众觉得“这事我身边真有人干过”。** 真实感来自人物当下怎么做，不来自旁白解释，也不来自一串看起来很完整的金句。

### 1. 先把因果写顺，再追求反转

- **消息、动作、反应必须有来源**：对方为什么发这句话、女主为什么看见、闺蜜为什么在场，都要在画面里交代；禁止为了制造实锤突然弹出关键证据。
- **少用一步到位的戏剧处理**：现实里的受气方通常先愣、确认、留证，再决定怎么处理；不要一上来就公开曝光、全群审判、所有人集体站队。
- **反派的狡辩要符合现场**：先否认、找借口、推责任是常见反应；女主只抓住一个事实回击，不安排对方连续说出方便剧情的自曝台词。
- **道具必须提前埋下**：结尾要用蛋糕、快递、工牌、群公告等道具反杀，第一段就让它自然出现在现场，不能到结尾凭空出现。

### 2. 台词像人说话，不像文案在总结

- 一句只承担一个动作或判断，能用短句就不用长句；30 秒三段里，每段只留一个主要信息点。
- 删除“我原谅的是过去的你”“这是给感情画句号”一类脱离现场的漂亮话，改成当事人看着具体证据说出的判断，例如“字是你打的”“这账我算得明白”。
- 金句要有**前面的事实托底**：先让观众看见备注、消息、蛋糕等细节，再让女主补一句；不能只靠台词告诉观众谁对谁错。
- 女主可以冷静，但不能像没有感情。允许出现停顿、看一眼旧物、说“可惜”，再转入清醒反击；“舍不得”与“及时止损”同时存在，比单纯无所谓更像真人。

### 3. 终局必须“看得见”，不能只靠离开

- S5 的现实反杀不能以“她哭了/她走了/她删了联系人”单独收尾，必须有一个改变现场局势的可见动作：把道具交还、当面转账、摘下戒指、撕掉合照、关掉共享账号等。
- 视觉动作要服务人物逻辑，不追求无缘无故的砸东西、泼水、扇耳光；动作越大，因果越要简单，观众静音也能看懂谁拿走了什么、谁留下了什么。
- 终局台词分两层：先用一句共情句承认代价，再用一句短反杀完成落点。例：“七年是可惜。可因为舍不得，再搭七年进去，那才叫亏。”
- 最后一拍结束在动作的结果上：对方抱着被退回的礼物僵住、女主带走代表共同经历的物件、门关上硬切。不要用连续三句价值观总结把情绪说完。

### 4. 共情与评论引导要从剧情里长出来

- 共情句优先写观众正在纠结的选择：舍不得还是止损、解释还是留证、体面还是争一口气；不要直接替观众下结论。
- 置顶评论用二选一或开放选择题，让观众讲自己的经历，例如：“七年舍不得，和再搭七年进去，你会怎么选？”不要用“想看后续就关注”冒充互动。
- 评论区回复也要像这个女主，不写统一鸡汤；围绕视频里的具体道具、事实和选择接话，让观众有继续讲故事的理由。

### 5. 交稿前的真人感检查

逐条问自己：

1. 如果删掉旁白，观众能不能从动作和道具看懂冲突？
2. 这句话是人物此刻会说的，还是作者替她写的总结？
3. 对手的反应是否符合现实，还是为了被打脸而配合？
4. 结尾有没有提前埋过、能被看见的视觉动作？
5. 看完后观众会复述哪个细节、会在哪个选择上留言？

若答案依赖解释、金句或突然出现的证据，先改因果和动作，不要继续堆台词。
