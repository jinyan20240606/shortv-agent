## 抖音账号信息设置

> 账号信息是用户关注前的第一印象，必须与"搞笑女"人设高度统一。头像、昵称、简介三者形成人设闭环，让用户刷到视频后能立刻理解"这是个搞笑号"。

### 7.1 基础信息

| 字段 | 内容 | 设计逻辑 |
|------|------|---------|
| **昵称** | `离谱本人` | ① "离谱"点明内容方向——做的事都离谱 ② "本人"暗示"我就是这样，不是演的" ③ 短、好记、有辨识度 |
| **抖音号** | `lipu_9527` | 9527 是周星驰经典编号，带无厘头喜剧基因，与搞笑赛道呼应 |
| **头像** | 搞怪自拍风格：女主对着镜头做夸张表情（瞪大眼/张大嘴/歪嘴笑），背景日常 | ① 夸张表情=搞笑信号，用户一眼知道这是搞笑号 ② 不做精致自拍——精致=美女赛道，搞怪=搞笑赛道 ③ 表情要"离谱"——正常人不这么拍照 |
| **背景图** | 日常场景抓拍：女主在某个离谱场景中（比如在超市滑购物车、在火锅店端锅），配文"我做的事都很合理啊" | ① 强化"离谱但合理"的人设 ② 配文用第一人称，与视频风格一致 |
| **简介** | `我做的事都很合理，是你们格局小了。\| 关注我，每天带你见识一个新离谱。\| 商务：xxx@xxx.com` | ① 三行结构：第一行点明"离谱但自洽"，第二行引导关注，第三行商务 ② 语气是"陈述事实"而非"开玩笑"——她真的觉得自己做的事很合理 ③ 每行 ≤15 字，手机端不折行 |

### 7.2 备选方案

| 方案 | 昵称 | 适用场景 |
|------|------|---------|
| **A（推荐）** | `离谱本人` | 主方案，短、好记、辨识度高 |
| **B** | `今天又离谱了` | 更直白，首屏即知内容方向，适合快速起号 |
| **C** | `离谱行为大赏` | 合集感更强，适合内容积累到一定量后 |
| **D** | `她好像觉得自己很正常` | 带第三方吐槽视角，适合"社死翻车型"内容偏多的账号 |

### 7.3 简介爆款文案库（按人设类型匹配）

> 简介是账号的"第二首帧"——用户点进主页后 3 秒内决定关不关注。以下文案按人设类型分类，每条都带"金句感"，让用户看完想评论或关注。

| 人设类型 | 简介文案 | 爆款逻辑 |
|---------|---------|---------|
| **S·离谱行为型（主推）** | `我做的事都很合理，是你们格局小了。\| 关注我，每天带你见识一个新离谱。\| 商务：xxx` | ① 陈述事实语气，不解释不讨好 ② "格局小了"带挑衅感，引发吐槽欲 ③ 每行 ≤15 字，手机端不折行 |
| **S·脑回路清奇型** | `我的脑回路，导航都导不明白。\| 你们觉得离谱？我觉得很合理啊。\| 商务：xxx` | ① 首句直接立人设，画面感强 ② 反问句激发用户反驳欲（评论区预定） |
| **S·社死翻车型** | `我不尴尬，尴尬的就是别人。\| 翻车是我的日常，圆回来是我的本事。\| 商务：xxx` | ① "我不尴尬"是经典梗，老粉看了会心一笑 ② 暗示"翻车"内容方向，新粉秒懂 |
| **A·一本正经胡说型** | `我认真起来，我自己都怕。\| 别笑，我做的真的是正经事。\| 商务：xxx` | ① "认真"和"怕"形成反差 ② "正经事"是反讽，懂的都懂 |
| **B·自黑型** | `我先笑为敬，你们随意。\| 我的缺点？那可太多了，一个一个讲。\| 商务：xxx** | ① 自黑=接地气，路人缘好 ② "一个一个讲"暗示内容量 |

**简介优化铁律**：
1. **首行定人设**：用户扫一眼主页，首行必须让他知道"这是个什么号"
2. **每行一个金句**：每行都能单独截图发朋友圈，才算合格
3. **留白制造互动欲**：不要解释太多，留"槽点"让用户想评论
4. **商务行放最后**：不影响前三行的信息密度

### 7.4 评论区互动运营（涨粉核心引擎）

> 评论区是涨粉的第二战场。一条爆款视频的评论区互动量，决定了它能不能二次推流。以下模板按场景分类，直接套用。

#### 7.4.1 用户夸赞类回复

| 用户评论 | 女主回复 | 设计逻辑 |
|---------|---------|---------|
| "笑死我了" | `笑归笑，我做的事真的很合理好吗 😏` | ① 接住笑点，同时延续人设 ② "真的很合理"是核心人设 |
| "太离谱了" | `离谱？这叫创新，你们格局小了 📋` | ① 用"格局小了"回应，符合角色宪法 ② 📋 emoji 强化"官方认证"感 |
| "这姐们太搞笑了" | `搞笑？我认真的好吗 💅` | ① 否认"搞笑"，强调"我是认真的" ② 认真做离谱事=反差笑点 |
| "你是怎么想到的" | `这还用想？正常人都会这么做吧 ✨` | ① 把离谱行为说成"正常人都会" ② 强化"我觉得我很正常"的人设 |
| "好喜欢你的视频" | `眼光不错，你是关注我的人里最有品位的 😌` | ① 夸对方眼光=夸自己，一箭双雕 ② 让被回复的用户有"被翻牌"的获得感 |

#### 7.4.2 用户质疑/杠精类回复

| 用户评论 | 女主回复 | 设计逻辑 |
|---------|---------|---------|
| "这怎么可能" | `你不信？说明你没见过世面 🤷‍♀️` | ① 不解释不证明，直接降维打击 ② 把质疑归因到对方"没见过" |
| "太假了" | `假的？那你解释一下为什么我觉得很合理 🤔` | ① 用荒谬逻辑回应荒谬质疑 ② 反问把球踢回去 |
| "这女的有病吧" | `病？我这叫创新思维，你不懂正常 🧠` | ① 把骂名接住并转化成"你不懂" ② 不生气不破防，保持人设 |
| "尴尬死了" | `尴尬？我不尴尬，尴尬的就是别人 🏆` | ① 经典梗回应 ② 保持"我不觉得尴尬"的人设 |
| "取关了" | `取关记得排队，前面还有 9527 个 😘` | ① 不挽留，反而暗示"关注我的人很多" ② 9527 呼应抖音号，老粉懂梗 |

#### 7.4.3 主动引导互动（小号/评论区自导）

| 场景 | 小号提问 | 大号回复 | 目的 |
|------|---------|---------|------|
| 新号起号期 | "这是真的吗？" | `真的呀，我每天都是这样过的，习惯了 😌` | 制造"真实感"争议，引发路人讨论 |
| 离谱行为型段子 | "她是怎么做到的" | `这还用想？正常人都会吧` | 强化"我觉得我很正常"的收编逻辑 |
| 社死翻车型段子 | "好尴尬啊哈哈哈" | `尴尬？我故意的，这是行为艺术 🎭` | 接住笑点，延续人设 |
| 脑回路清奇型段子 | "她的脑回路好清奇" | `清奇？我觉得很有道理啊 😇` | 假装不懂"清奇"是贬义，强化自洽 |
| 一本正经胡说型 | "她好认真啊哈哈哈" | `认真怎么了？我做的是正经事！` | 越认真越好笑 |

#### 7.4.4 评论区运营铁律

1. **前 30 分钟必回**：视频发布后 30 分钟内，至少回复 5-10 条评论，触发算法"高互动"标签
2. **每条回复都带人设**：不能出现"谢谢""好的"等正常回复——出戏即掉粉
3. **置顶一条"引战评论"**：自己用小号留一条争议性评论，大号回复后置顶，引导路人下场吵
4. **回复带 emoji**：每个回复至少 1 个 emoji，增加视觉记忆点
5. **不删负面评论**：骂评=互动量，只要不涉及敏感词，留着让其他用户反驳

### 7.5 置顶视频策略（主页转化率）

> 置顶视频是用户点进主页后决定"关不关注"的关键。三条置顶各司其职，形成转化漏斗。

| 置顶位 | 选品逻辑 | 推荐内容 | 目的 |
|-------|---------|---------|------|
| **第 1 条（最左）** | 点赞最高的爆款 | 数据最好的那条（不限类型） | 用数据说服新用户"这个号值得看" |
| **第 2 条（中间）** | 最能体现人设的段子 | 推荐一条"离谱行为型"段子 | 让新用户 30 秒内理解"她是什么人" |
| **第 3 条（最右）** | "自我介绍"类段子 | 用段子形式拍"你们是不是都好奇我为什么这么离谱？我觉得我很正常啊。"——不是真介绍，是延续人设的段子 | 解决"这人到底是真的还是演的"的疑问，同时强化人设 |

**置顶更新规则**：
- 每出一条新爆款（点赞 > 历史最高），替换第 1 条置顶
- 第 2 条固定不动，除非出了更能代表人设的 S 档段子
- 第 3 条每 2-3 周换一次，保持主页新鲜感
- 置顶视频的评论区也要运营（见 7.4 节），新用户点进去看到活跃评论区，关注率更高

### 7.6 账号人设统一规则

| 维度 | 规则 | 示例/说明 |
|------|------|---------|
| **第一人称** | 所有简介、置顶视频文案、评论区回复都用"我"视角 | "我做的事都很合理""你们格局小了"——不用"本小姐""本仙女"等二次元感过强的自称 |
| **评论区人设** | 女主账号在评论区回复时，保持"离谱但自洽"的语调 | 正例：用户说"笑死"→ 回复"笑归笑，我做的事真的很合理"；反例：用户说"笑死"→ 回复"谢谢"（太正常，出戏） |
| **视频文案（标题）** | 每条视频配一句"女主视角"的标题，不用客观描述 | 正例："今天在火锅店搞了个效率革命"；反例："火锅店段子"（太正常，出戏） |
| **更新频率** | 日更 1-2 条，固定时间发布（推荐 12:00 午休 + 20:00 晚高峰） | 固定时间培养用户习惯，算法也更容易识别账号活跃度 |
| **合集分类** | 按场景建合集：`🍲 吃饭篇` `🏢 办公室篇` `🚇 出行篇` `🏠 日常篇` | 合集名用 emoji + 2-4 字，用户刷到合集入口就知道内容方向 |
| **话题标签** | 每条视频固定带 `#搞笑女` `#离谱日常` `#搞笑段子`，再加场景标签如 `#火锅店` | 前三个标签固定，场景标签按当期内容换 |

#### 7.7.1 起号期节奏与数据复盘模板

**发布节奏**：
- 前 6 条每天 1 条，第 7 天开始日更 2 条
- 前 3 条发完后，看哪条数据好，第 4-6 条往那个方向微调
- 第 7 条开始加入评论区互动运营（用小号提问"这是真的吗"，大号回复维持人设）
- 10 条发完后复盘，按数据倾斜

**数据复盘模板（每条发完后 24h 填写）**：

| 指标 | 达标线 | 爆款线 | 本条数据 | 判断 |
|------|-------|-------|---------|------|
| 完播率 | ≥25% | ≥40% | | |
| 点赞率 | ≥3% | ≥6% | | |
| 评论率 | ≥0.5% | ≥1.5% | | |
| 转发率 | ≥0.3% | ≥1% | | |
| 关注转化率 | ≥1% | ≥3% | | |

**数据驱动决策规则**：
1. **完播率高 + 点赞率高** → 场景和类型都对，继续出同类型同场景
2. **完播率高 + 点赞率低** → 场景对但离谱度不够，下一轮加大离谱程度
3. **完播率低 + 评论率高** → 争议性强但内容留不住人，优化首帧钩子
4. **转发率高** → 圆场够离谱，后续保持 H11 超现实加码
5. **关注转化率高** → 人设辨识度强，加大该类型产出

**起号期关键动作时间线**：

| 时间 | 动作 | 目的 |
|------|------|------|
| 发前 30min | 用小号在同类爆款视频评论区引流（不违规的前提下） | 冷启动种子用户 |
| 发后 0-30min | 大号回复 5-10 条评论（用 7.4 模板） | 触发算法高互动标签 |
| 发后 1h | 置顶一条"引战评论" | 引导路人下场讨论 |
| 发后 24h | 填写数据复盘模板，决定下一条方向 | 数据驱动迭代 |
| 每 3 条 | 对比前 3 条数据，砍掉最低效的场景/类型 | 快速试错，集中资源 |
