# 童年往事切片剧 · 主角人设与人物关系

> **用途**：定义主角原型和核心人物关系网，是成长主线的骨架。所有切片剧本的人物都从这里取。
> **状态**：示例素材版，待创作者用真实信息替换/修正。
> **原则**：人物关系要能跨年龄段回扣（童年的人，少年/青年再出现），才能撑起追更养粉。

---

## 一、主角人设

### 1.1 基本信息

| 维度 | 设定（示例，可改） |
|------|----------------|
| 姓名 | 小宇（童年）/ 宇哥（少年外号）/ 本名待定 |
| 性别 | 男 |
| 年代 | 90 后（锚定 90 年代童年，受众最大盘） |
| 童年性格 | 慢热闷骚型，生人面前老实、熟人面前爱打闹，本性偏老实但偶尔犯贱不懂事 |
| 少年性格 | 开始装酷、逞强、暗恋不敢说、对爸妈叛逆又心软，慢热在社交中慢慢打开 |
| 青年性格 | 回望时才懂那些事的意义、嘴上不说心里有数 |
| 核心缺陷 | 嘴硬死要面子不认错 + 慢热不敢表达（这是成长弧线的"要改的东西"） |
| 核心优点 | 本性老实、重感情、讲义气、对弱者心软 |
| 家庭底色 | 农村家庭，爸妈都是种地的农民，分房居住，从小和姥姥那辈最亲、常去姥姥家玩（给"被偏爱"留空间） |

### 1.2 人物核（三条铁律，对标搞笑赛道角色宪法）

> 主角的行为逻辑必须始终一致，不能这集一个性格下集另一个性格。

1. **嘴硬到底，死不认错**：闯了祸第一反应是狡辩，哪怕证据确凿也要嘴硬。但嘴硬完会偷偷补救——这是"老实人嘴硬"的反差萌。
2. **慢热闷骚，熟了才闹**：生人面前老实安静，熟人面前爱打闹犯贱。这个"慢热→打开"的过程本身就是成长线——观众追的是"这个闷葫芦什么时候敢表达"。
3. **重感情但不表达**：对姥姥/发小/小狗的感情很深，但从不当面说，都是用行动偷偷表达（如把好吃的留给姥姥、替发小扛事）。死要面子，被拆穿了就恼羞成怒，但事后会自己别扭地弥补。

### 1.3 成长弧线（跨年龄段的主线）

| 年龄段 | 性格状态 | 核心母题 | 弧线变化 |
|--------|---------|---------|---------|
| **童年（6-12）** | 慢热闷骚，生人老实熟人闹，偶尔犯贱闯祸 | 天真闯祸、被偏爱、第一次失去 | 不懂事但重感情，慢热还没打开 |
| **少年（13-18）** | 装酷逞强，青春期，社交慢慢打开 | 叛逆、暗恋、友情考验、升学压力 | 开始懂事但死要面子，慢热在破冰 |
| **青年（19+）** | 回望者 | 独立、选择、和解 | 终于能说出当年没说的话，慢热彻底打开 |

**主线钩子**：观众追的是"这个慢热嘴硬的老实孩子，最后能不能学会认错和表达感情"——这是贯穿几百条的成长悬念。

### 1.4 视觉锚（供 AI 流水线）

| 维度 | 设定 |
|------|------|
| 童年 | 虎头虎脑、短发、校服/背心短裤、膝盖常带疤、缺颗牙（可换牙期） |
| 少年 | 开始留发型、校服拉链不拉、单肩背书包、长高变瘦 |
| 青年 | 干净利落、眼神比童年沉、嘴角有童年没有的笑意 |
| 一致性要求 | 同一张脸的渐变，五官特征（眉眼/嘴型）跨年龄段可辨认是同一人 |

## 二、核心人物关系网

> 设计原则：每个核心人物都要能跨年龄段回扣，才能撑追更。
> 配比：1 主角 + 2 家人 + 2 同辈 + 1 "变化型"角色 = 6 人核心局。

### 2.1 家人线（情感底色）

#### 姥姥（核心情感锚，"被偏爱"的来源）

| 维度 | 设定 |
|------|------|
| 定位 | 主角最深的情感羁绊，从小和姥姥那辈最亲、常去姥姥家玩，"偷偷偏爱"他的人 |
| 性格 | 偏心外孙、护短、有好吃的第一个留给小宇、嘴上骂心里疼 |
| 功能 | 暖条主力（被偏爱的瞬间）、泪条伏笔（离别线） |
| 跨年龄段 | 童年常去姥姥家 → 少年时主角嫌她唠叨去得少了 → 青年回望才懂她 |
| 弧线 | 童年的"靠山" → 少年的"嫌烦" → 青年的"遗憾"（可设离别线，泪条爆款储备） |

#### 妈妈（规则与冲突来源）

| 维度 | 设定 |
|------|------|
| 定位 | 种地农民妈妈，忙、心软不舍得打孩子，爱得笨拙 |
| 性格 | 心软、刀子嘴豆腐心、急了才拍两下、从不道歉但会用行动补偿（如骂完给做好吃的） |
| 功能 | 暖条主力（心软的母爱、偷偷护着孩子）、笑条辅助（急了拍两下的名场面） |
| 跨年龄段 | 童年护着他 → 少年吵不过他了但还是会护 → 青年发现妈妈老了 |
| 弧线 | 童年的"护身符" → 少年的"唠叨" → 青年的"和解" |

#### 爸爸（缺席式存在，留白角色）

| 维度 | 设定 |
|------|------|
| 定位 | 种地农民爸爸，忙于农活、严父，批评教育为主，急了会揍 |
| 性格 | 严厉、讲道理多过动手、但脾气上来下手没轻没重、揍完不道歉但会默默给修好弄坏的东西 |
| 功能 | 笑条主力（挨打名场面，农村严父揍孩子共鸣极强）、暖条（严厉背后的笨拙父爱）、泪条伏笔 |
| 跨年龄段 | 童年怕他、挨揍 → 少年敢顶嘴了但还怕 → 青年理解了严厉背后的苦心 |
| 弧线 | 童年的"对立面/怕" → 少年的"战场" → 青年的"读懂严厉" |

### 2.2 同辈线（友情/成长镜像）

#### 发小·磊子（友情主线，"一起长大"的载体）

| 维度 | 设定 |
|------|------|
| 定位 | 隔壁家孩子，从小一起长大，主角最好的朋友 |
| 性格 | 比主角稳、胆子小、被主角带着闯祸、关键时刻讲义气 |
| 功能 | 笑条（一起闯祸）、暖条（友情考验）、追更钩子（"他现在还联系吗"） |
| 跨年龄段 | 童年一起闯祸 → 少年一次闹翻 → 青年重逢 |
| 弧线 | 童年的"共犯" → 少年的"闹翻与和好" → 青年的"各自人生" |
| 追更价值 | "发小现在怎样了"是观众最想追的线之一 |

#### 同桌/同学·一个女孩（暗恋线，青春期增量）

| 维度 | 设定 |
|------|------|
| 定位 | 少年期出现的角色，主角暗恋对象（童年篇不出现，少年篇引入） |
| 性格 | 待定（建议：文静/开朗二选一，和主角形成反差） |
| 功能 | 少年篇泪条/暖条主力（暗恋不敢说）、追更钩子（"后来有没有说出口"） |
| 跨年龄段 | 少年出现 → 青年是否重逢 |
| 弧线 | 少年的"没说出口" → 青年的"释怀或遗憾" |
| 注意 | 童年篇不引入，避免触碰未成年人早恋红线；少年篇处理为"懵懂好感"尺度 |

### 2.3 变化型角色

#### 一只狗/一个物件（"失去与成长"的载体）

| 维度 | 设定 |
|------|------|
| 定位 | 童年养的小动物（或某个重要物件），承载"第一次失去" |
| 功能 | 泪条爆款储备（失去/离别，对接感动公式第3墙） |
| 跨年龄段 | 童年失去 → 青年回望时翻出旧物（如 s002 的狗绳） |
| 弧线 | 童年的"第一次知道留不住" → 青年的"和解" |

## 四、人物使用规则

1. **一条切片最多 2-3 个人物**：童年篇以小宇 + 1 家人/1 同辈为主，不堆人
2. **人物出场按年龄段**：童年篇只用家人（姥姥/妈妈/爸爸）+ 磊子 + 狗；暗恋女孩少年篇才引入
3. **每个核心人物都要有"跨年龄段回扣"**：不能只在一个年龄段出现就消失，否则追更养粉不成立
4. **人物性格不能崩**：参照主角三条铁律，每个配角也要有自己的一致性（如姥姥始终偏心、妈妈始终心软护短、爸爸始终严厉）
5. **真实素材替换时，人物原型对齐**：创作者的真实家人/发小对应到这些角色，性格可调但功能位不变
