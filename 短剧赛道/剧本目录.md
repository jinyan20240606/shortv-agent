```

- 序号 / 年龄段 / 情绪点 / 时长 / 集体共鸣钩 / 追更钩子 / 真实内核

| 角色 | 定位 | 默认状态 | 提示词标签 |

## 场景设定

## 切片正文（小说原文级叙事，分场）
### 场1：首帧钩子（0-3s）
[小说级叙事 + 旁白台词 + 表演/镜头/提示词]
### 场2：情境铺陈（3-15s）
...
### 场3：情绪爆发（15-35s）
...
### 场4：情绪落点（35-42s）
...
### 场5：追更钩子（42-45s）
...

## 视频制作解析提示
- 分镜清单 / 关键画面 / 年代细节 / AI生成提示词汇总
```

> 此格式兼顾"可读的小说级叙事"和"可解析的结构化元数据"，后续可程序化解析提取分镜和提示词。
