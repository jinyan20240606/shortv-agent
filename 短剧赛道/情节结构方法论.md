# 童年往事切片剧 · 情节结构方法论

> **用途**：定义每条切片的叙事结构，是剧本创作的骨架公式。
> **依据**：[`viral-short-form`](.claude/skills/viral-short-form/SKILL.md) 推荐的爆款短视频叙事结构 `Hook → Escalation → Payoff → CTA`，适配"童年回忆改编"的题材特性。
> **和搞笑赛道的区别**：搞笑赛道是"打脸爽感"三拍；本赛道是"情绪共鸣"回忆叙事——payoff 不是打脸，是"戳中观众的那一下"。

---

## 〇、时长怎么定（先读）

> **时长不是拍脑袋定的，由"情绪类型 + 内容复杂度"决定。定错时长直接拉低完播率。**
> 依据 [`viral-short-form/formats.md`](.claude/skills/viral-short-form/references/formats.md)：Storytime（叙事共鸣）25-60s、Meme/relatable（"就是我"）5-15s、POV 10-25s。

### 0.1 按情绪类型定时长（核心规则）

| 情绪 | 对应 skill 格式 | 建议时长 | 为什么 |
|------|---------------|---------|--------|
| **笑条** | Meme/relatable + POV | **20-40s** | 笑点要快，铺垫太长笑点就凉了；但童年笑条要一点情境，不能像纯 meme 那么短 |
| **泪条** | Storytime | **40-60s** | 情绪需要铺垫和酝酿，太短来不及酝酿情绪，观众哭不出来 |
| **暖条** | Storytime | **35-55s** | 暖需要慢慢渗透，比笑条长，比泪条略短 |
| **燃条** | Storytime | **30-50s** | 需要铺垫低谷才能燃起来，但不能拖 |

**一句话**：**笑条求快（20-40s），泪条求酿（40-60s），暖条居中（35-55s）。**

### 0.2 时长的底层逻辑

```
时长 = 情绪酝酿所需时间
- 笑：情绪是"瞬间爆发"→ 短
- 泪/暖：情绪是"逐渐渗透"→ 长
```

- **不要为了长而长**：能 30 秒说完的泪条，别硬撑到 60 秒注水——中段注水=完播暴跌
- **不要为了短而砍**：泪条硬压到 20 秒=情绪没酝酿够=观众没共鸣就结束了

### 0.3 时长红线

| 红线 | 说明 |
|------|------|
| **最短不低于 15s** | 低于 15s 装不下"钩子+情绪核+落款"，太仓促 |
| **最长不超过 70s** | 超过 70s 完播率断崖，童年切片不是长视频 |
| **起号期偏短** | 起号前 30 条，同类情绪取时长下限（笑条 20s、泪条 40s）——新号完播压力大，短一点稳 |
| **成熟期可放长** | 有粉丝基础后，泪条可放到 55-60s 充分酝酿情绪 |

### 0.4 时长与结构的对应（40s 泪条示范）

| 结构段 | 占比 | 40s 泪条 | 20s 笑条 |
|--------|------|---------|---------|
| Hook | ~8% | 0-3s | 0-2s |
| Escalation | ~55% | 3-25s | 2-12s |
| Payoff | ~25% | 25-37s | 12-18s |
| CTA | ~8% | 37-40s | 18-20s |

> 规律：无论多长，Hook 恒定 2-3s（前 3 秒定生死），Escalation 占大头，Payoff 留够冲击时间，CTA 干脆利落。时长变化主要吃在 Escalation 段。

## 一、核心骨架（Spine）

> 直接采用 skill 的 `Hook → Escalation → Payoff → CTA`，映射到童年切片。

```
Hook（0-3s）        → 首帧钩子：一句话把陌生人拉进共同记忆
   ↓ but/therefore
Escalation（中段）   → 情绪爬升：铺陈情境 + 冲突/糗事/温情逐级加码，不平铺
   ↓ but/therefore
Payoff（情绪落点）   → 兑现钩子承诺：戳中观众的那一下（笑点炸/扎心一句/暖到破防）
   ↓
CTA（结尾）         → 一个低摩擦动作：追更钩子 / 评论区共鸣提问 / "你呢？"
```

**节拍连接铁律**：拍与拍之间用 **"但是/所以"**，不用 **"然后"**。能用"然后"连的第二拍，说明它不该存在。

---

## 二、Hook：首帧钩子（0-3s，决定生死）

> skill 铁律：hook 承担 80% 留存，1-3 秒内必须"把陌生人拉进来"。

### 2.1 童年切片专用钩子原型（从 skill 10 型里选最适配的 6 型）

| # | 钩子原型 | 童年切片用法 | 示例 |
|---|---------|------------|------|
| 1 | **直接点名（Direct call-out）** | 点名"有过同款经历"的观众 | "你小时候挨过最冤的一顿打是什么？" |
| 2 | **好奇缺口（Curiosity gap）** | 抛一个未解的小悬念 | "那天我妈没打我，我反而慌了。" |
| 3 | **中途切入（In media res）** | 直接从事件高潮切入，后解释 | 画面：小孩弹起来关电视 + "门锁一响，我魂都飞了。" |
| 4 | **代价自白（Mistake confession）** | 坦白一个童年"翻车" | "我第一次撒谎，撑了不到十分钟。" |
| 5 | **反差claim（Bold claim）** | 一个反预期的判断 | "我最好的朋友，是从一场打架开始的。" |
| 6 | **失去预告（Stakes）** | 预告一个情感代价 | "你小时候丢过最想找回来的东西吗？我丢过一只狗。" |

### 2.2 钩子构造三招（来自 skill）

1. **Staccato open（短句连击）**：首句用短句，高信息密度，砍连接词。正例："狗窝空了。我扔下书包就往街上跑。" 反例："那是一个平常的下午……"
2. **蒙音也能懂**：首帧画面自带信息（空狗窝/弹起关电视），静音也知道发生了什么
3. **念出声自检**：说一遍超过 2 秒或磕巴，就砍短

### 2.3 钩子反模式（禁止）

- ❌ 慢热铺垫："那是一个平常的下午，阳光很好……"
- ❌ 自我介绍："大家好，今天讲个我小时候的故事"
- ❌ 反问让观众转弯猜（"你猜怎么着？"）——直接给信息
- ❌ 钩子承诺了 payoff 不兑现（最伤完播和信任）

## 三、Escalation：情绪爬升（中段，防流失）

> skill 铁律：中段最容易 flatline（bleeds out）。每一拍必须比上一拍"多一点"，curiosity/emotion 持续复利。

### 3.1 童年切片的三级情绪梯

| 级 | 做什么 | 必须"多"出来的东西 |
|----|--------|------------------|
| **1. 情境铺陈** | 快速交代时间/地点/在干嘛 | 让观众"进入场景"，产生"我也这样过"的代入 |
| **2. 冲突/温情加码** | 事件往前推一步，张力上升 | 一个新信息/新动作（如音量调大了、门锁响了） |
| **3. 逼近落点** | 推到情绪临界点 | 观众开始"预感到要发生什么"（悬着的一口气） |

### 3.2 Re-hook（中段再钩，来自 skill）

中段情绪最容易松的地方，插一个"但是/没想到"的小转折，重新拉回注意力：
- "本来以为这事就这么过去了，但是——"
- 画面上一个意外动作（妈妈摸电视后盖）

### 3.3 Pattern reset（模式重置）

每 2-4 秒换镜头/景别/画面信息，眼睛不"看腻"。切片虽短，也要有画面节奏变化（全景→特写→反应镜头）。

---

## 四、Payoff：情绪落点（兑现钩子）

> 这是童年切片和搞笑赛道最大的不同：**payoff 不是"打脸爽"，是"共鸣到位"的那一下。**

### 4.1 四种情绪的 payoff 定义

| 情绪 | payoff 是什么 | 判断标准 |
|------|--------------|---------|
| **笑条** | 笑点炸开的那一下 | 观众"哈哈哈"，想发给同龄人 |
| **泪条** | 扎心/破防的一句 | 观众"绷不住了"，想起自己的事 |
| **暖条** | 暖到心里的瞬间 | 观众"破防了/想家了"，想收藏 |
| **燃条** | 逆袭/突破的爽感 | 观众"爽了/被激励" |

### 4.2 Payoff 硬约束

1. **兑现钩子承诺**：钩子说了"最冤的打"，payoff 必须给到"冤"的那一下（真相不重要，多挨两下）
2. **一句话点睛**：payoff 常落在一句可复述、可截图的旁白上（如"那个笑，比打我还可怕"）
3. **front-load 保险**：把第二强的情绪点放在中段偏前（扛过早期流失），最强的留 payoff
4. **不能埋太深**（skill 失败模式3）：payoff 别拖到最后才来，中段要给"一点味道"

### 4.3 点睛金句原则（童年切片版）

> 不同于搞笑赛道的"毒舌金句"，本赛道的金句是**"举重若轻的一句真话"**。

- **举重若轻**：用平淡的话说重的情绪。正例："那是我第一次知道，有些东西不是你等就能回来的。"
- **不说教**：讲故事，不讲道理。反例："这告诉我们要珍惜。" 正例：让观众自己品
- **可复述**：短、真、能被观众抄进评论区

## 五、CTA：结尾（低摩擦，驱动追更/互动）

> skill 铁律：CTA 只给一个低摩擦的 ask，绑定 payoff。

### 5.1 童年切片的三种 CTA

| 类型 | 做法 | 适用 |
|------|------|------|
| **追更钩子** | "这是后话了" / "那又是另一个故事" | 养追更黏性（爬坡期后加强） |
| **共鸣提问** | "你小时候呢？" / 把钩子问题重复一遍 | 拉评论区"我也是"（验证期主力） |
| **回环收尾** | 结尾一句让首帧那句话重新有味道 | 驱动重播（skill 强调 loop end to start） |

### 5.2 CTA 硬约束

- 只给**一个** ask，不要又追更又提问又关注堆一起
- 验证期以**共鸣提问**为主（拉互动），爬坡期后转**追更钩子**（养黏性）

---

## 六、双线叙事（Dual Narrative，来自 skill）

> 旁白说一件事，画面show另一件互补的事，眼睛耳朵各有信息，注意力翻倍。

- **旁白**：成年主角的回忆口吻（举重若轻、带一点自嘲或温情）
- **画面**：童年场景的具象重演（小孩的动作、表情、道具）
- **配合**：旁白说"我装作什么都没发生"，画面show小孩握着倒着的作业本——反差出笑点
- **铁律**：两条线互补，不能矛盾（旁白说难过，画面别搞笑）

---

## 七、过山车节奏（Pacing，来自 skill）

```
快钩子（fast in，无铺垫）
  → 中段带一个情绪峰（让它喘口气，落一个高情绪点）
  → 极快收尾（clip hard，结尾别拖，或回环到首帧）
```

- 镜头/画面每 2-4 秒一变
- 砍掉一切废帧：开头结尾的沉默、"呃""然后"、logo

---

## 八、三种失败模式自检（来自 skill，每条剧本过一遍）

| 失败模式 | 症状 | 修法 |
|---------|------|------|
| **弱钩子（0:01就走）** | 首句平淡、慢热、自我介绍 | 用更利的钩子原型重写前 3 秒，直接上 payoff 或 stake |
| **无爬升（中途流失）** | 开头还行，中段flatline | 早埋 open loop，重排让张力上升，插 re-hook |
| **payoff埋太深（中段弃）** | 好东西来太晚 | payoff 提前，压缩铺陈，钩子里先透一点味道 |

---

## 九、硬约束速查（生成每条剧本时逐条对照）

| # | 硬约束 | 验收方法 |
|---|--------|---------|
| C1 | **首帧 3 秒有钩子**，用 6 型之一，带集体共鸣 | 念出声，3秒内陌生人是否被拉进来 |
| C2 | **单条只打一个情绪点**（笑/泪/暖/燃） | 一条里是否只有一个情绪落点 |
| C3 | **陌生人独立可看**（验证期），不依赖前情 | 假设观众没看过前面，是否看得懂 |
| C4 | **拍间用"但是/所以"连接**，不用"然后" | 检查拍间逻辑词 |
| C5 | **payoff 兑现钩子承诺** | 钩子的promise在payoff是否给到 |
| C6 | **点睛金句举重若轻、不说教、可复述** | 金句是否短真、能抄进评论区 |
| C7 | **双线叙事**：旁白 vs 画面互补不矛盾 | 旁白情绪和画面是否一致方向 |
| C8 | **CTA 单一低摩擦**：验证期共鸣提问，爬坡期追更钩子 | 结尾是否只有一个ask |
| C9 | **过三种失败模式自检** | 弱钩子/无爬升/payoff埋太深逐项排查 |

## 十、结构模板（写剧本时套用）

```
## 元数据
序号 / 年龄段 / 情绪点 / 时长 / 钩子原型 / 集体共鸣钩 / CTA类型 / 真实内核

## Hook（0-3s）
[画面：静音可懂的钩子画面]
旁白：[短句连击，6型钩子之一，带集体共鸣]

## Escalation（中段）
[级1 情境铺陈] —— 但是/所以 ——
[级2 冲突/温情加码] —— 但是/所以 ——
[re-hook：一个意外转折]
[级3 逼近落点]
（双线：旁白回忆口吻 + 画面童年重演）

## Payoff（情绪落点）
[兑现钩子的那一下]
点睛金句：[举重若轻、可复述]

## CTA（结尾）
[追更钩子 / 共鸣提问 / 回环收尾，三选一]
```

> 现有 [s001 剧本](scripts/01-童年篇/s001-偷看电视被抓.md) 的五段结构（首帧钩子→情境铺陈→情绪爆发→情绪落点→追更钩子）即此 spine 的落地版：首帧钩子=Hook，情境铺陈+情绪爆发=Escalation，情绪落点=Payoff，追更钩子=CTA。
