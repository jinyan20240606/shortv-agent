# 童年往事切片剧 · 赛道定位手册

> **赛道名**：短剧赛道（童年往事切片剧）
> **母赛道**：无（独立赛道）
> **创建日期**：2026-07-24
> **一句话定位**：把创作者本人的真实童年/少年经历改编成 AI 短剧切片，像电视剧主角一样有一条"我从小到大的那些事"的主线，用连续切片日更养粉、追更破圈。
> **本文件是该赛道唯一事实来源**：立项标准、审核红线、内容模型、创作规则以此为准。

---

## 〇、赛道核心逻辑

### 0.1 这是什么

- **形态**：AI 短剧切片，单条 30-90 秒，日更/高频更新
- **主线**：一个主角（创作者本人原型）从童年 → 少年 → 青年，像电视剧主角一样有完整成长主线，观众追"这个人后来怎样了"
- **素材内核**：创作者的真实童年/少年经历（不限于校园，含家庭/邻里/趣事/糗事），改编 + 适度虚构补充
- **情绪基调**：混合（搞笑 / 扎心 / 治愈交替），但**单条只打一个情绪点**
- **不是"校园题材"**：校园只是场景之一，核心是"一个人的童年往事连续剧"

### 0.2 商业模式：切片追更养粉

```
连续切片（主角慢慢长大）→ 追更黏性 → 养粉 → 破圈变现
```

- **不是**单条爆款自生自灭，**是**用连续性把"看过一条"变成"追一个人"
- 养粉命根子：观众和主角一起成长，产生"陪伴感"和"追更欲"

### 0.3 分阶段路线（硬约束：不要一上来赌几百条）

| 阶段 | 条数 | 目标 | 打法 |
|------|------|------|------|
| **验证期** | 前 20-30 条 | 验证题材有没有人看、形象能不能稳 | 每条"能独立看懂 + 暗含成长线"，不强依赖追更 |
| **爬坡期** | 30-100 条 | 靠某条爆款盘活系列 | 加强追更钩子，主角开始明显成长 |
| **连载期** | 100-几百条 | 拉长成长线，追更养粉 | 有存量粉后，追更逻辑才成立 |

> **验证期是起点，几百条连续是终点。** 别把终点当起点。

## 一、爆款切片的底层逻辑（冷启动核心）

### 1.1 连续剧模式的死穴与破解

**死穴**：连续剧要"追更"，但追更要先有存量粉；冷启动期没粉 → 死循环。

**破解（验证期铁律）**：**每条切片必须"陌生人也能独立看懂"**——
- 第 1 条推给从没看过的人，他没有前情，也能在 3 秒内进入
- 用"集体共鸣钩子"（下方 1.2）替代"前情依赖"
- 追更钩子是"加分项"，不是"及格线"——单条自己就得立得住

### 1.2 从"我的故事"到"我们的故事"（最重要的转译）

> **真实经历改编最大的坑：只有你自己觉得有意思。**
> 抖音用户不关心"你"经历了什么，只关心"这像不像我"。

| ❌ 个人流水账（没人看） | ✅ 集体共鸣（有人看） |
|----------------------|---------------------|
| "我小时候那年……" | "你小时候有没有过这样一件事……" |
| 讲我的独特经历 | 讲所有人都经历过的瞬间 + 我的独特细节 |
| "我"视角封闭叙事 | "你/我们"视角，把观众拉进来 |

**转译公式**：`集体共鸣的场景（大家都有）+ 你独有的细节（只有你有）= 既有共鸣又有记忆点`

- 集体共鸣的场景：偷看电视被逮、过年放炮、和邻居家小孩打架、被爸妈混合双打、第一次撒谎、养的小动物死了、转学第一天
- 你独有的细节：那个具体到别人模仿不了的瞬间（让内容不撞车）

### 1.3 首帧钩子（前 3 秒决定生死）

每条切片开头 3 秒必须满足其一：
- **集体记忆钩**："你有没有过……"（把观众拉进共同记忆）
- **反差钩**：一个和"童年美好"预期相反的画面（如"我最好的朋友，是从一场打架开始的"）
- **悬念钩**：一个未解的小问题（如"那天我爸为什么没打我"）

> 禁止用"大家好我今天讲一个故事"这类平铺开头——3 秒没钩子，直接划走。

## 二、内容模型：单条切片结构

### 2.1 标准切片结构（30-90 秒）

```
① 首帧钩子（0-3s）：集体记忆钩 / 反差钩 / 悬念钩，把陌生人拉进来
② 情境铺陈（3-15s）：快速交代"什么时候、在哪、发生了什么"，不铺垫
③ 情绪爆发（15-50s）：一个具体的冲突/糗事/暖心瞬间，单条只打一个情绪点
④ 情绪落点（50-70s）：这条的"意义"——笑点炸开 / 扎心一句 / 暖心收尾
⑤ 追更钩子（70-90s，加分项）：留一个"这个小孩后来怎样了"的成长悬念
```

### 2.2 单条只打一个情绪点（硬约束）

- 混合基调是**系列层面**的（这条搞笑、下条扎心、再下条治愈），**不是单条层面**的
- 一条里又搞笑又扎心又治愈 = 情绪散掉，观众记不住
- 每条创作前先定：这条是**笑条 / 泪条 / 暖条 / 燃条**，只打这一个点

### 2.3 情绪类型库（对接感动公式）

| 情绪类型 | 校园高频场景 | 对接人性十三墙（见 docs/touching-formula.md） |
|---------|------------|------------------------------------------|
| **笑条** | 糗事、闹剧、熊孩子操作 | —— |
| **泪条·离别** | 转学、毕业、老同学失联 | 第 3 墙（有限→留不住） |
| **泪条·孤独** | 转学第一天、没人玩、被孤立 | 第 2 墙（孤独→走进来） |
| **暖条·陪伴** | 同桌帮忙、朋友撑腰 | 第 2 墙 / 第 4 墙（被忽略→看见他） |
| **暖条·袒露** | 青春期的逞强被看穿 | 第 8 墙（伪装→交出来） |
| **燃条·成长** | 逆袭、第一次赢、突破自己 | 第 6 墙（会放弃→不松手） |

## 三、主角与成长线设定

### 3.1 主角原型

> 主角是创作者本人的改编原型。以下待创作者提供真实素材后填充：

| 维度 | 设定（待填） |
|------|------------|
| 性别 | 待定 |
| 童年性格关键词 | 慢热闷骚型（生人老实熟人闹）、本性偏老实但偶尔犯贱不懂事、嘴硬死要面子 |
| 家庭背景 | 农村家庭，爸妈都是种地的农民，分房居住，从小和姥姥那辈最亲、常去姥姥家玩（影响故事底色） |
| 视觉锚 | 待定（AI 形象需从童年到青年连续一致，由创作者流水线负责） |
| 成长弧线 | 待定（从童年到青年，性格如何变化） |

### 3.2 成长线设计原则

- **年龄递进要有"变化可见"**：不只是长高，而是性格/认知/关系的变化（如从"被欺负的怂孩子"到"敢还手了"）
- **埋长线钩子**：某些角色/物件/情结跨年龄段回扣（如童年的邻家小孩，少年时又遇到）
- **每个年龄段有母题**：童年=天真闯祸、少年=青春萌动与烦恼、青年=独立与选择

## 四、立项标准

### 4.1 立项三问（每条必过）

1. **陌生人能独立看懂吗？**（验证期铁律，不能依赖前情）
2. **有没有集体共鸣钩？**（"这像不像我"，不是"你真惨/你真好笑"）
3. **单条情绪点清不清晰？**（笑/泪/暖/燃，只有一个）

### 4.2 立项否决项（一条不满足就不做）

- [ ] 是否有集体共鸣（不是纯个人流水账）？
- [ ] 首帧 3 秒是否有钩子？
- [ ] 单条是否只打一个情绪点？
- [ ] 真实内核是否够独特（有别人模仿不了的细节）？

### 4.3 立项加分项

- 有追更钩子（成长悬念）
- 有可回扣的长线伏笔
- 情绪落点有金句（可截图、可复述）

## 五、审核红线

### 5.1 绝对禁止

- ❌ 霸凌美化（可以呈现，但必须有正向落点，不能渲染施暴爽感）
- ❌ 未成年人不当内容、早恋渲染
- ❌ 教师/家长/学校负面刻板抹黑
- ❌ 暴力、自残、极端负面情绪引导
- ❌ 地域/家庭背景歧视

### 5.2 需谨慎

- ⚠️ 涉及真实人物：改编要充分虚化，避免影射真实同学/邻居/家人引发纠纷
- ⚠️ 扎心内容：扎心要有出口（治愈/成长），不能纯致郁
- ⚠️ 怀旧年代感：年代细节要准（不同年龄段观众对童年记忆不同）

## 六、创作规则（切片生产 SOP）

1. **先定情绪点**：这条是笑/泪/暖/燃？
2. **选真实素材**：从素材库选一个真实瞬间
3. **做集体转译**：把"我的故事"翻译成"你有没有过……"
4. **写首帧钩子**：3 秒钩子（集体记忆/反差/悬念）
5. **写切片结构**：按 2.1 五段结构
6. **加追更钩子**：留成长悬念（加分项）
7. **过立项与红线**：按第四、五章逐条检查

## 八、产出规范

### 8.1 目录结构

```
短剧赛道/
├── 童年往事切片剧-定位手册.md   # 本文件
├── 主角与成长线.md              # 主角原型 + 成长线大纲（待素材填充）
├── 素材库.md                    # 创作者真实童年/少年经历素材（待填充）
└── scripts/
    ├── 01-童年篇/
    │   ├── s001-[标题].md
    │   ├── s002-[标题].md
    │   └── ...
    ├── 02-少年篇/
    └── 03-青年篇/
```

### 8.2 单条切片文件格式

每条切片包含：
- **元数据**：年龄段、序号、情绪点（笑/泪/暖/燃）、时长、集体共鸣钩、追更钩子
- **真实内核**：这条改编自哪个真实瞬间（一句话）
- **切片脚本**：按五段结构（首帧钩子/情境/爆发/落点/追更钩）
- **口播/台词**：完整旁白或对白
- **画面提示**：每段的画面描述（供创作者流水线制作）

### 8.3 质量验收

用 [`hit-preview`](.claude/skills/hit-preview/SKILL.md) 抽检：
- 前 3 秒钩子强度 ≥ 7/10
- 单条独立可看性（不依赖前情）通过
- 情绪点单一、清晰
