# 童年往事切片剧 · 选材与改编指南

> **用途**：回答两个最实操的问题——①拍什么样的趣事（选材筛选）②自己的真实故事怎么改编成爆款结构（改编流程）。
> **配套**：选材依据 [题材火度分级](题材火度分级与示范框架.md)，改编骨架用 [情节结构方法论](情节结构方法论.md) 的 Hook→Escalation→Payoff→CTA。

---

## 第一部分：拍什么样的趣事（选材筛选）

### 一、能爆的趣事，都符合"三有"

> 不是所有童年回忆都能拍。一个真实故事值不值得做，先过"三有"筛子。

| 筛子 | 问自己 | 不满足的后果 |
|------|--------|------------|
| **有共鸣** | 是"我们都经历过"，还是"只有我经历过"？ | 只有你经历过 = 没人有代入感 = 划走 |
| **有情绪** | 能不能让人笑/哭/暖/爽其中一个？ | 平淡无情绪 = 看完无感 = 不互动 |
| **有画面** | 有没有一个具体的、能拍出来的名场面？ | 没有画面 = AI 拍不出 = 干巴巴 |

**一句话**：**大家都有的场景（共鸣）+ 一个有情绪的瞬间（情绪）+ 一个能拍的画面（画面）= 能爆的趣事。**

### 二、四类最容易拍的趣事（按情绪分）

| 情绪 | 拍什么 | 判断"值不值得拍" |
|------|--------|----------------|
| **笑** | 你干过的蠢事/糗事/被抓包 | 现在讲出来还想笑 = 值得 |
| **泪** | 你失去的东西/离别/没说的话 | 现在想起来还会揪一下 = 值得 |
| **暖** | 谁偷偷对你好/被偏爱的瞬间 | 现在想起来还暖 = 值得 |
| **燃** | 你第一次做成/逆袭/突破 | 现在想起来还骄傲 = 值得 |

> **自检口诀**：一个童年片段，如果你现在讲给朋友听，朋友会有反应（笑/"我也是"/"好惨"/"好暖"）——就值得拍。如果朋友"哦"一声，就别拍。

### 三、不要拍的趣事（避坑）

| 不拍 | 原因 |
|------|------|
| 太私人的（只有你懂的梗） | 没共鸣，别人 get 不到 |
| 太平淡的（没有情绪起伏） | 看完无感 |
| 太复杂的（要讲很多前情） | 切片装不下，观众没耐心 |
| 涉及霸凌/家暴且无正向出口的 | 触红线，致郁劝退 |
| 太"凡尔赛"的（炫耀童年优越） | 招黑，观众反感 |

## 第二部分：真实故事怎么改编成爆款结构（改编流程）

> **核心认知**：真实故事往往是"流水账"，直接讲没人看。改编 = 把流水账重组成 Hook→Escalation→Payoff→CTA 的爆款结构。
> **改编不是编造**，是"重新排列真实素材的顺序和重点"，保留真实内核，强化情绪冲击。

### 一、改编五步法

```
第1步：提炼情绪核 —— 这个故事最戳人的是哪一下？（定 Payoff）
第2步：找钩子 —— 用什么把陌生人 3 秒拉进来？（定 Hook）
第3步：砍枝叶 —— 只留通往情绪核的必要情节（定 Escalation）
第4步：翻译成"我们的" —— 把"我"的故事变成"你有没有过"（定共鸣）
第5步：加落款 —— 结尾一句点睛 + 一个 CTA（定收尾）
```

### 二、逐步拆解（附实例）

**原始真实素材（流水账版）**：
> "我小时候有次偷看电视，把音量调大了，我妈从地里回来发现电视是热的，就知道我看了，但她没说什么，就笑了一下。"

---

#### 第1步：提炼情绪核（定 Payoff）

问："这个故事最戳人的是哪一下？"

- 不是"偷看电视"（这只是背景）
- 是"我妈什么都没说，只是笑了一下——那个笑比打我还可怕"

→ **Payoff = 妈妈那个"了然的笑"**。这是全片的情绪落点，所有内容都为这一下服务。

#### 第2步：找钩子（定 Hook）

问："用什么 3 秒拉住陌生人？"

- 用"直接点名"钩子原型：**"你偷看电视，有没有忘关过音量？"**
- 这句话瞬间唤起所有 80/90 后的同款记忆 → 共鸣建立

#### 第3步：砍枝叶（定 Escalation）

问："哪些情节是通往 Payoff 必须的？哪些可以砍？"

保留（必要）：
- 偷偷开电视（建立紧张）
- 音量不小心调大（埋隐患）
- 门锁响、慌忙关电视、电视还在发热（危机爆发）

砍掉（无关）：
- 那天演的什么动画片（无关）
- 我看了多久（无关）
- 后来作业写没写（无关）

→ 只留"开电视→音量调大→门锁响→关电视→电视发热"这条通往 Payoff 的线。

#### 第4步：翻译成"我们的"（定共鸣）

问："怎么把'我的故事'变成'你也经历过'？"

- 旁白用"你/我们"视角开场，把观众拉进来
- 强化"每个人都干过"的普世动作：偷偷开电视、耳朵贴喇叭、假装写作业
- 加一个所有人都懂的细节：作业本是倒着的（装学习没装好）

#### 第5步：加落款（定收尾）

- **点睛金句**（举重若轻）："我妈心软，从小舍不得打我——但那个笑，比打我还可怕。"
- **CTA**（共鸣提问 + 追更钩子）："你小时候偷看电视被抓过吗？——从那以后我都备把扇子，这是后话了。"

---

#### 改编成果对比

| | 原始流水账 | 改编后爆款结构 |
|---|-----------|--------------|
| 开头 | "我小时候有次偷看电视" | "你偷看电视，有没有忘关过音量？"（钩子） |
| 中段 | 平铺直叙 | 开电视→音量调大→门锁响→慌忙关（有张力的 Escalation） |
| 高潮 | "我妈笑了一下" | "我妈心软舍不得打我——但那个笑，比打我还可怕"（Payoff 点睛） |
| 结尾 | 无 | "你被抓过吗？备把扇子这是后话了"（CTA+追更） |

> 完整成品见 [s001 剧本](scripts/01-童年篇/s001-偷看电视被抓.md)。

### 三、改编三大原则

1. **真实内核不动，排列重点可调**：不编造没发生的事，但可以调整讲述顺序、放大某个细节、砍掉无关枝叶
2. **一条只讲一个情绪核**：一个真实故事如果有多个情绪点，拆成多条，不要一条讲完
3. **情绪核决定一切**：先定"最戳人的那一下"，再倒推钩子和情节。不知道情绪核在哪 = 这个故事还不能拍

### 四、改编自检清单

改编完一条，逐项检查：

- [ ] 情绪核清不清晰？（一句话能说出"最戳人的是哪一下"）
- [ ] 钩子够不够强？（3 秒能不能拉住陌生人）
- [ ] 有没有砍干净？（有没有和情绪核无关的废情节）
- [ ] 翻译成"我们的"了吗？（是"你有没有过"还是"我经历过"）
- [ ] 点睛金句可复述吗？（能不能被观众抄进评论区）
- [ ] 单条只有一个情绪点吗？（没有又笑又哭又暖）

## 第三部分：快速改编模板（照着填）

> 有一个真实故事，照这个模板填空，就能出一版爆款结构。

```
【真实素材】：[用一两句话写下你的真实回忆，流水账没关系]

【第1步·情绪核】：这个故事最戳人的是____（笑点/泪点/暖点，具体到哪一下）

【第2步·钩子】：用____钩子（直接点名/好奇缺口/中途切入/代价自白/反差claim/失去预告）
  → 首帧那句话："你有没有过____"

【第3步·Escalation】：通往情绪核的必要情节（3-4 步，用"但是/所以"连）
  1. ____
  2. 但是 ____
  3. 所以 ____

【第4步·共鸣】：所有人都懂的普世细节：____（让观众代入）

【第5步·落款】：
  - 点睛金句：____（举重若轻、可复述）
  - CTA：____（共鸣提问"你呢？"/追更钩子"这是后话了"）
```

## 第四部分：从素材库到剧本的完整流程

```
真实回忆（流水账）
   → 过"三有"筛子（有共鸣/有情绪/有画面）
   → 判断情绪类型（笑/泪/暖/燃）
   → 用改编五步法重组成爆款结构
   → 套 [情节结构方法论](情节结构方法论.md) 的模板写成小说级剧本
   → 登记进 [剧本目录](剧本目录.md)
   → 按 [发布节奏](发布节奏与内容日历.md) 排期发布
```

> **给创作者的话**：你的真实故事是这个赛道最大的护城河——别人可以抄题材，抄不了你独有的细节。改编的本质不是"编得更精彩"，是"把真实里最戳人的那一下，用爆款结构放大给观众看"。
